# 下一阶段研究决策：MaxViT 三维断层分割

日期：2026-09-17。性质：现有结果审计与研究建议；本次没有启动、终止训练或修改训练/评估代码。

## 1. 结论

建议保留 MaxViT 为骨干，研究“断层面的几何信息如何改善弱断层识别与跨数据集迁移”。域内精度保持竞争力，跨域效果与几何质量提供额外价值。当前结果只能支持这一研究假设，尚不能声称新模型稳定优于强基线，也不能保证 TGRS 录用。

不建议继续大范围扫模型宽度、无针对性叠加注意力，或者为了拉开模型差距人为降低数据质量。IoU 约 0.83 也不足以证明数据集已经饱和或没有改进空间。

## 3. 先修正评估，再投入新训练

1. **文件覆盖**：train/evaluate.py:69 始终写 run/test.json。启动脚本先评 legacy、再评本地 Wu，后者覆盖前者。应输出 eval/<dataset>/<split>/<checkpoint>.json，记录数据 manifest/hash、模型、种子、checkpoint/hash、选择指标、阈值、样本量、坐标轴、预处理、指标定义。
2. **容差召回率公式错误**：train/eval_cross.py:70–74 把匹配到真值邻域的“预测体素数”用于 Recall 分子。正确召回应为 |Y ∩ dilate(P)| / |Y|；Precision 为 |P ∩ dilate(Y)| / |P|，二者必须分别累计。现有 tol2_recall 作废、需重评。普通 IoU/P/R/AP 不受该公式错误影响。当前 max_pool3d(5) 定义的是 Chebyshev 距离 2，不是欧氏距离 2。
3. **checkpoint 一致性**：当前评估读取 best.pt，A 组配置 select=loss；源码未见独立保存 best-IoU checkpoint。不能直接拿曲线峰值作为已测试权重的成绩。后续统一按源验证 IoU 选择，保存 loss-best 和 IoU-best 两套并明确主协议，历史结果保留原协议。
4. **域差异诊断**：核查轴顺序、标准化、标签厚度、频带、噪声、断距和分辨率。对少量固定样本展示 seismic/GT/probability/prediction/error 五联图。高 P 低 R 可能涉及厚度与校准，也可能是真正漏检；仅靠汇总分数不能认定原因。
5. **主指标保留严格 IoU**，另报告 AP、P/R、分类型结果和正确的距离容差指标。表面指标对厚度差异也并非完全不敏感，必须写明提取与容差规则。不得为了分数选择性膨胀某个模型输出。
6. **避免持续使用最终目标集调参**：已有 Wu20 已多次查看，应承认其开发期使用。后续模型选择主要依赖固定源验证与源域模拟风格验证；最终增加未参与设计的外部数据/空间隔离区域，不把反复查看的结果称为完全盲测。

## 4. 建议的一条模型主线

### 研究假设

断层是二维曲面嵌入三维体。普通网格注意力的联系不一定沿断层面传播；仅拟合体素标签也可能学习合成器的波形、层理与标签宽度特征。研究几何监督能否让 MaxViT 在保留域内精度的同时，提高弱断层面的覆盖和跨数据集稳定性。这是待检验假设，不是已证实原因。

### 第一版只做一个机制：预测几何引导的注意力

- 从现有强 MaxViT baseline 出发，保留其 block/grid 结构、全分辨率分支和 decoder，不同时改宽度、loss 主项、训练日程。
- 在一个中间尺度（优先 32³）增加轻量法向预测头。训练用合成器断层面及法向，推理只用输入地震预测法向。
- 将预测方向转成注意力的软几何偏置，让局部同面方向更容易传递信息；限制在已有注意力候选集合和适当距离范围内，避免跨越弯曲面时强行套用平面近似。
- 保留原注意力/残差通路，几何偏置强度可学习并受限。先验证不会把邻近但独立的断层粘连。
- 交汇、分叉、最近面不唯一的位置，单法向监督并不成立：根据合成实例几何屏蔽或降低这些位置的法向监督权重；不删掉其分割监督。法向 n 与 -n 应等价。
- 初版不把低分辨率二值 fault mask 简单平均后当几何真值；从原曲面/可信近面点采样，处理变换后的坐标、方向和体素间距。

这比重新堆一层通用 attention 更容易形成与地震任务相关的可验证机制。但“方向引导注意力”本身不能未经系统检索就宣称首创。

### Loss 先保持最小

第一版：L = L_seg + lambda_n L_normal。

- L_seg 保留基线 Dice+Focal，使结构收益可归因。
- L_normal = 有效近面点上 mean[1 - (n_pred · n_gt)^2]，两者单位化；以有效点数归一化，排除交汇歧义点。
- 消融必须包含“只有法向辅助头、不影响 attention”，以区分多任务监督收益与几何注意力收益。
- 不同时加入 clDice、边界 loss、Tversky、距离 loss 等。旧版几何 loss 没有稳定收益，不能仅改名继续叠加。

第二版仅当第一版有效，再引入受控的同几何、不同成像风格的一致性约束：

- 对同一地质模型改变子波主频/相位、带宽和噪声，保留几何标签；参数范围从源数据/物理假设确定，不拟合最终测试集。
- 成对输入均有分割监督，再增加前景均衡、可信区域内的一致性项，防止背景主导或把不可见弱断层强行当作可辨识目标。
- 数据增强与一致性已有广泛先例；贡献必须来自具体方法和证据，不能把通用一致性本身当新发明。

## 5. 最省资源的验证顺序

### 阶段 A：先做现有权重审计

无需重训，先修评估并分别保存各数据域结果，补每体 TP/FP/FN、AP/PR 曲线和固定可视化。确认收益究竟来自减少整段漏检、改变厚度还是阈值校准。这一步能决定是否值得做几何机制。

### 阶段 B：单种子筛选一个机制

同一新版 v2 数据、相同划分与训练协议，从随机初始化训练：

1. 强 MaxViT baseline。
2. MaxViT + 法向辅助头。
3. MaxViT + 法向头 + 几何注意力。

先用固定中期预算筛查数值稳定性和机制是否工作；中期结果不能作为最终排名。只有候选有一致趋势才训练到预定终点。主要看源验证 IoU/AP、困难类别召回、错误连接与源域风格扰动验证，而非不断查询 Wu20。

如果只改训练策略即可解决问题，不强行把收益归因于模型结构。

### 阶段 C：验证结构收益不等于增强收益

核心 2×2：原 MaxViT / 新模型 × 原增强 / 同几何风格增强。再单独加入一致性项，避免把增强和一致性混为一个效应。公平地给 UNet 同样的数据与增强预算。

### 阶段 D：最终实验

- 最终三者：充分训练的强 UNet、原 MaxViT、候选模型，至少 3 个随机种子。
- 补一个领域专用强基线（如 Fault-Net）；若主张泛化方法优越，还需同目标的通用增强/一致性对照。不能只击败未经调好的小 UNet。
- 数据范围收敛到：新版源数据、一个外部合成集、一个独立真实工区。无需把所有训练→微调→迁移组合全做一遍。
- 真实工区优先有可用人工断层标注者；若只拿到稀疏标注，只在已标注区域计算指标，不能把未标注处视为背景。无标注工区只能作定性展示。
- 报告严格 IoU、AP、P/R、困难类别及形态质量，附 Params/FLOPs/显存/实测推理时间；匹配前向 FLOPs 与匹配参数量分别描述。
- 对同一体的模型差值做配对分析，按独立体/工区块重采样估计不确定性；不把数百万相关体素当独立样本。
- 关键模型从头训练，权重初始化和预训练来源一致或明确分组。若使用预训练，基线也给同等机会。

## 6. 继续/停止标准

先定义实用差异阈值，再看结果。可暂设源域 IoU 下降容忍度为 0.5 个百分点，外部泛化目标为 2–3 个百分点、且多个种子方向一致；这些只是项目筛选标准，不是统计显著性判据或 TGRS 录用门槛。

- 新模型源域持平、外部与几何质量稳定改善、成本可解释：适合以泛化与断层结构恢复为主线。
- 新模型源域/跨域均有改善：可写统一的精度与稳健性主线。
- 只在单种子、单一目标上改善约 1 个百分点：先补重复与误差分析，不急于写“显著提升”。
- 公平增强后新结构收益消失：结构路线证据不足，应转向真正有效的训练机制或重新立题，不能靠删去强对照维持结论。

## 7. 参考依据与创新边界

- [MaxViT 原论文](https://arxiv.org/abs/2204.01697)：block/grid 局部与全局建模是已有设计，不能直接作为新的地震方法贡献。
- [FaultSeg3D 官方仓库](https://github.com/xinwucwp/faultSeg)：训练/验证示例为合成数据。
- [Fault-Net / MD Loss](https://arxiv.org/abs/2110.05319)：已针对断层边缘特性使用高分辨率传播和多尺度融合，应比较其与候选设计的差异。
- [2026 修订的地质断层大规模基准](https://arxiv.org/abs/2505.08585)：已研究 FaultSeg3D、CRACKS、Thebe 的域变化、训练策略与结构偏差，因此“发现跨域下降”本身不构成足够的方法创新。
- [Domain Randomization and Pyramid Consistency](https://arxiv.org/abs/1909.00889)：风格随机化与一致性并非新概念。
- [TGRS 官方范围](https://www.grss-ieee.org/publications/transactions-on-geoscience-remote-sensing/)：要求新的方法进展和有意义的研究；没有某个 IoU 分差即可录用的规则。

总体判断：目前有值得继续的混合建模信号，但缺少稳定的新方法增益和真实地震证据。近期优先级是“评估审计 → 单一几何机制 → 公平增强对照 → 多种子与一个真实工区”，不是再扩大无针对性的模型搜索。
