# 论文路线图 — 2026-09-18

## 一、论文主脉络(一句话)

**在算力对等、评价协议封闭的前提下,MaxViT 式三维断层网络相对卷积 U-Net 有稳定但不大的优势;
优势在合成数据上被标签天花板压平,在真实工区(Thebe)上仍然存在;文章把"怎么公平地测"和"测出来多少"一起交代清楚。**

叙事顺序(引言 → 结论):

1. 问题:文献里断层分割的分数从 0.18 到 0.87 都有,同一数据集也差 4 倍——协议不一致、基线容量不对等、软 Dice 被背景地板主导、实际数据只给定性图。
2. 数据:复现 Su 2026 的断层网络合成(5 类,1000 体)和 Wu 2019 式合成(1000 体),生成器开源;旧难集作第三套。
3. 模型:MaxViT-tiny 编码器 + 三项修正(全分辨率 skip、drop-path、128 分区),各有单项消融;Context-Grid 跨尺度解码器(浅层 Query 查深层上下文,block/grid 两种视野)及其 conv/block/grid/both 消融。
4. 损失:软 Dice 的背景地板分解(五模型表:地板项占断层体积 2–16%,能翻转模型排序),平方分母修正 + 按 IoU 选点。
5. 协议:算力对等(FLOPs 匹配)而非参数对等;Thebe 空间封闭协议(32 剖面缓冲带、逐道信号掩膜、中心 64³ 计分、验证区选点、测试区封存)。
6. 结果:
   - 合成同分布:所有结构挤在 1.5 点内(标签可观测性天花板),说明合成集不能区分模型;
   - 旧难集算力对等:MaxViT-tiny 0.628 > 混合 0.622 > UNet 0.599;
   - Thebe 测试区:MaxViT 0.390 > UNet-L 0.377(UNet 用 2× FLOPs);AP +2.6,recall +3.2;Context-Grid 待定;
   - 零样本到 Wu 公开体、JINTAN 实际工区定性图;
   - ODS/OIS 副表,与 An 2021 / CIG-Bench 并排,说明协议差异。
7. 结论:结构收益是二阶(1–3 点),但方向一致且在实际数据上保持;更大的收益应来自预训练与数据(future work)。

## 三、判定规则(提前写死)
- Context-Grid vs MaxViT-tiny:测试 IoU ≥ +1 且 conv 消融明显低于 both → 解码器进主线;否则作消融章节,主线为"编码器 + 修正 + loss + 协议"。
- 多 seed:报均值 ± 标准差;差距小于标准差的不写成"优于"。
- 所有和文献的数值对比只在同协议下进行;跨协议只做定性说明。
