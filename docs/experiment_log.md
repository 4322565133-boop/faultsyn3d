### 1.6 对 Su 方法的发现(F 系列)

**F1 目标函数只约束拓扑符号**。Eq. 43–45 只是 `Δ₀·Δₖ` 的符号条件。倾角、尺寸、间距、曲率一个都没约束。这是从方程直接看到的。

**F2 分支倾角完全自由**。纯复现下随机可行解的分支倾角散布 5°–89°,大量 1°、5°、7° 近水平面。
```
en_echelon  00   dips=[74, 34, 15,  7]
horsetail   01   dips=[68, 35, 24,  5]
listric     01   dips=[50,  1,  1,  1,  0]
```

**F3 X 边不保证可见的穿切**。基线 20 个 flower 卷:面间二面角 9.1°–72.7°(中位 35.1°),倾向相反的只有 9/20。9° 的两片面基本平行,剖面上看不出穿切。

**F4 收敛行为与论文 Fig. 12 不同,但已解释**。我们浅树 1–2 代归零,论文 8–13 代;我们深树 86–92% 归零率,论文说总能收敛。
- 200 粒子初始化后的全局最优:我们 0 / 0 / 260 / 301 / 562(五类),论文 78 / 160 / 1070 / 860 —— **量级一致,d_z 没有标定错**
- 浅树 1 代归零的原因:可行解密度 1.4%,200 粒子至少一个可行的概率 94%
- 深树不收敛的原因仍未定位;论文说的"总能收敛"我们做不到

**F5 参考平面相交 ≠ 曲面相交**。Su 的流程是「优化参考平面 → 弯成 Bézier 曲面」,中间无反馈。Algorithm 4 只管"弯曲不能制造禁止的相交",没有规则管"弯曲不能破坏要求的相交/间隔"。实测:positive_flower 参考平面相距 0.16 体素,弯完 28.4;en_echelon 四片 (P,P) 只隔 0.35–6.3 体素。

**F6 标签与可见性脱节**(最重要)。Su 标的是几何面,不管该处滑移多少。三个公式叠加:
- Eq. 16 Hermite 滑移场在断层边缘衰减到零
- Eq. 28 分支 d_max = 主 × √(N_i/N_0),分支只有主的一半左右
- Hermite 场 h(u)h(v) 在全面上的均值 **0.25**:无论 d_max 多大,平均滑移只有峰值的 1/4 → 约一半面积必然低于分辨率(与参数无关的结构性结论)

实测(v12 纯复现,λ/4 ≈ 2.1 样点):主断层只有 22–49% 面积可见,分支大量 0%。`phi_dis` 68–88°(纯走滑)时走滑型类别可见面积仅 6.5%;降到 35–55° 后升至约 40%,是 Hermite 衰减允许的上限附近(纯倾滑也只有 47%)。

**F7 Fig. 15 是精选展品**。Fig. 14 图注明说 "user-defined tree structures";Fig. 15 每行第 2、3 格是教学式构造演示;分支大小形状高度一致,随机采样做不到。加上 F1–F3,结论:**Fig. 15 的规整形态超出了该目标函数所能保证的范围**。

**F8 PSO 性能瓶颈**。`g_int` 的 `_rect_corners` 每次评估对每对断层算两次,一次 PSO 调 48 万次。改为每次评估算一次 + 手写 3-向量运算 + 停滞早停(patience=30),单卷 85s → 16s。

## 3. 数据集创新尝试(模块 1)—— 历史与结论

### 3.1 尝试过的项

| 项 | 主张 | 证据状态 | 结局 |
|---|---|---|---|
| `g_dip` | 分支倾角在 Anderson 带内 | 消融(旧代码):去掉后 <20° 分支 0→6.2% | 保留在代码,关闭 |
| `g_int` | 标 P 的对不相交 | 消融:去掉后交叉率 8.4→16.9% | 同上 |
| `g_dup` | 分支不塌缩成主断层复制品 | 消融:去掉后塌缩 10→18%;反例 horsetail 三支 [89,89,89] | 同上 |
| `G_obs` | 落差 ≥ λ/4 | **消融证伪**:AUC +0.000;被 `g_dip` 完全覆盖 | 已删 |
| `g_cross` | X 边参考矩形须在盒内相交 | **证伪**:参考矩形本就相交(0.16),惰性 | 已删 |
| `g_conj` → `g_dip_rel` | 逐边规定子/父倾向相反或相同 | v11 实测 78% 边满足(基线掷硬币) | 保留,关闭 |
| `g_present` | 分支中心须在盒内 | 单例 14%/2% → 46%/32% | 保留,关闭 |
| `g_sep` | P 对最小间距 | **证伪**:测中心到平面距离,对错开的面无效 | 该删 |
| 修复遍(Step 3b) | 弯曲后在真实曲面上强制贴合/分开 | 5 例测试按拓扑正确 | 保留,关闭 |
| 曲率符号继承 | 分支按类别继承母断层弯曲方向 | 反向设定拆散交叉(0.16→28.4) | 保留,关闭 |

### 3.2 学到的六条

1. **目标函数只看得见参考平面**。依赖最终曲面的性质写进目标函数都白搭(`g_cross`、`g_sep`、曲率拆散交叉,三次失败同一原因)。
2. **冗余项毁掉消融**。`G_obs` 替 `g_dip` 挡着,让消融测不出 `g_dip` 的贡献。
3. **测错对象给假信心**。每项的验证指标必须在最终数据上算。
4. **逼近精选展示图不是研究目标**。
5. **复现暴露的缺口(F1–F6)才是科学发现**。
6. **规整可能有害**。约束越多多样性越低,CNN 靠多样性泛化。这是必须专门测的失败模式。

### 3.3 决定

从写论文角度,数据集创新要证明得"同一模型在 N 套数据集上各训一次、在真实数据上评",代价大、效应可能小或负。**决定放弃作为贡献**,全部开关关闭:

```python
use_geometry_objective   = False
use_surface_repair       = False
inherit_branch_curvature = False
```

保留在仓库作 future work。F1–F7 作为"对 Su 方法的分析"写进论文一节,不主张修好了它。

### 3.4 备选:若日后要做,正确的做法

三个轴,每轴对应一个基线上可证明的缺陷,5 arm 消融(基线、+A、+B、+C、+ABC):
- A 几何合理性:`g_dip` + `g_dup`
- B 拓扑落实:`g_int` + `g_dip_rel` + `g_present` + 修复遍 + 曲率符号
- C 可观测性:`phi_dis` 标定 + 标签规则
预判下游效果 C > A > B;B 最可能有害。
