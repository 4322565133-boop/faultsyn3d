# 几何引导 MaxViT：训练前研究方案 v1

日期：2026-09-17。状态：方案已制定，未实现候选网络、未启动本轮正式训练，也未改变已有进程。沿用 TGRS_RESEARCH_DECISION_20260917.md 的审计结论。

## 1. 科学问题与可证伪假设

问题：不同成像风格下，如何保持断层面覆盖，减少弱响应区域漏检，同时避免相邻断层错误连接？

假设 H1：曲面法向辅助监督能改善 MaxViT 的断层几何表征。
假设 H2：将预测法向用于局部注意力偏置，比仅增加辅助监督更有效。
假设 H3：收益在不同训练种子与外部数据上仍存在，而不是单一标签厚度、阈值或源数据风格带来的偶然现象。

H1/H2 不成立就不继续堆模块；若只有增强有效，应如实转向训练方法研究。新增模块名称暂为 Geometry-guided MaxViT，不能预先宣称首创或优越。

v2 主标签使用 labels；实例、曲面和法向只用作训练期辅助监督。confidence 是位移/可见性代理，不是人工检测可信度，不作为网络输入，不据其删除主分割真值。

### v2 已知优点与不足

- 平均断层体素占比 3.4754%，已保存 193×193 的逐实例曲面、实例标注、生成元数据。
- 配置主频 24–34 Hz、采样间隔 0.004 s、SNR 8–22 dB，成像域仍较窄。
- 铲状、马尾结构含较弱响应；记录的可见性代理均值约 0.744、0.778，不能解释成人类可见比例。
- 现有 UNet-L 在验证集铲状类 IoU 0.7166，雁列类 0.9019，困难并不均匀，不能说总体 IoU 0.83 就已饱和。
- 每类使用固定树结构模板加参数变化；随机样本划分能检查同分布泛化，不能证明对未见拓扑模板的泛化。
- 现有 geometry_model_upgrade_v1 缓存版本为 label_pca_r4_k128_v1，来自二值标签局部 PCA，不是真实曲面法向；不能直接当作新的曲面监督真值。

### 固定划分

读取原 manifest，不重洗牌：每类 train160、val20、test20。所有模型共享同一划分。任何同一地质模型的成像变体都继承原始划分，不能跨 train/val/test。

- train800：梯度更新与训练增强。
- val100：checkpoint、少量预声明超参数选择；主要选择指标为严格 voxel IoU@0.5。
- 固定风格验证：只从 val100 派生少量预定义扰动，作稳健性诊断；不能算独立新样本，也不另按此挑一个跨域专用 checkpoint。
- test100：正式候选确定后统一评估一次；历史已反复查看，因此标为已有基准，不再声称未见盲测。
- 论文定稿前另生成新种子的确认集，例如 100 个、每类 20，保持主数据 1000 个不变。提前冻结生成配置，不能看分数后筛样本。该集合检验当前方案的确认性表现，不消除此前所有研究选择偏差，也不替代真实工区。

## 3. 第一版网络——最小改动验证 H1/H2

基础：models/maxvit3d.py 的 MaxViT3DUNet，full_res_skip=True、drop_path_rate=0.2、img_size=128，约 40.16M 参数。

原编码尺度（D×H×W，通道）：
128³输入 → 64³/64 → 32³/64 → 16³/128 → 8³/256 → 4³/512。
原 U 型卷积解码器与 128³ 浅层细节分支保留，输出 128³ 分割 logits。

只修改 32³ 阶段的一个局部 block-attention，保留原 grid-attention 负责跨窗口联系：

1. 从该 block 输入特征预测三维方向 n_hat，并单位化；用轻量 1×1×1 投影/小 MLP。
2. 在原 QK/sqrt(d)+相对位置偏置上加一个有界几何偏置，不新增全局密集 attention。
3. 对同窗口点 i,j，可先使用对法向符号不敏感的局部平面偏离惩罚：
   g_ij = -[(n_i·r_hat_ij)^2 + (n_j·r_hat_ij)^2]/2。
   自连接设 g_ii=0；r_hat 由统一坐标/体素间距计算。偏置为 beta*g，beta 有界，初始为 0 或很小。
4. 沿局部切平面的联系较少受惩罚，穿越法向的联系较多受惩罚；原注意力/残差始终保留。
5. 第一版不对远距离 grid token 强加同一平面假设，避免弯曲断层与远处邻近平面被错误建模。后续若扩展 grid 引导，应作为独立实验。

该设计有明确风险：在背景/交汇处预测法向不可靠，局部面法向也不等于断层实例归属。首版必须观察错误连接与方向头行为，不能只看平均 IoU。

训练和推理的 attention 都只能读取预测法向；禁止训练时把真实法向直接注入 attention 后再在推理换成预测值。真实几何仅进入辅助 loss。辅助头也可作为“训练期额外监督”的贡献，要给基线相同信息的对照。

## 4. 曲面监督和 loss

新缓存应独立命名，不覆盖旧 PCA 缓存。从 surfaces/f_i 的有效网格差分或三角片叉积计算法向；核查其与最终标签坐标一致。处理 NaN、裁切边界、退化三角形、不同断层近邻与交汇、同一粗尺度单元的多个不一致法向。

监督只采样可信单一曲面点；不跨相反符号法向直接线性插值，插值应做符号对齐或在离散点监督。转换 xyz→zyx、尺度、旋转、翻转时同时变换位置与方向。各实例分层采样，避免大主断层占满监督点。排除歧义仅针对法向 loss，不删除分割标签。

L = 0.6 L_Dice + 0.4 L_Focal + lambda_n L_normal。
L_normal = sum_valid[1-(n_hat·n_gt)^2]/N_valid，空有效集合返回可微零值。

初始 lambda_n=0.05，作为工程起点而非最优结论；先检查其梯度量级。训练前 10 epochs 逐渐引入几何项与偏置，20 epochs 到全权重；无额外训练轮数。若不稳定，预声明只允许在源验证上比较 0.02/0.05/0.1，并给完整实验记录。

第一版不加 clDice、Tversky、边界 loss 或一致性，便于判断结构是否有效。

## 5. 训练协议与顺序

本次不启动训练。下次按下列顺序推进。

### P0：修评估和准备监督

- 修复容差 Recall；为不同数据域和 checkpoint 独立输出结果。
- 固定归一化、阈值、轴顺序、split/hash、每体结果与模型配置。
- 单独保存 val-IoU-best 和 val-loss-best，主结论用 val-IoU-best。
- 导出基线错误图和 per-class 指标，完成几何缓存正确性验证。

### P1：实现后做小规模检查

- 关闭几何偏置时与原网络输出一致；共享部分初始化一致。
- 合成平面/曲面法向正确，旋转翻转一致，交汇掩码有效。
- 辅助分支/注意力偏置有梯度，AMP loss 有限。
- 小数据过拟合、4 卡 DDP 一致性与断点续训检查。
- 实测 Params/FLOPs/显存/步耗时，再确定每卡 batch；若不能每卡 2，用梯度累积保持 global batch 8，并向基线对齐。

### P2：单种子筛选后完成 200 epochs

| ID | 模型 | 目的 |
|---|---|---|
| B0 | UNet-L base42，约 9.64M | 强 CNN 基线 |
| B1 | 原强 MaxViT，约 40.16M | 主对照 |
| A1 | MaxViT + 法向辅助头，不改 attention | 验证 H1 |
| A2 | A1 + 几何注意力偏置 | 验证 H2 |

建议先 B1/A1/A2，用同一源验证比较；B0 也必须按相同终点完成，历史 56 epoch 结果只作参考。前 60 epochs 用于中期检查，不和别人 200 epoch 成绩做最终排名；仅数值异常、明确失效或预声明停止规则触发时终止，不因暂时落后随意砍掉某组。

共同协议：随机初始化，seed2026，200 epochs，AdamW lr=1e-4、weight_decay=0.01；10 epoch warmup，之后 cosine 到 1e-7；AMP 前向、FP32 loss；global batch8。四卡 DDP；几何与图像增强一致。先沿用历史共同增强保持可比，物理风格增强作为下一阶段单独因素。具体运行保存配置与源码 hash。

学习率范围与预算对各模型公平；如明显存在架构专属不收敛，允许同等预算的源验证调参并报告，不能把未经合理训练的基线作为最终对照。

### P3：候选有效后做增强对照与最终复现

- 原 MaxViT/新模型 × 原增强/受控成像增强的 2×2；UNet 也给相同增强。
- 如加入成对一致性，单独比较“同样增强，无一致性”与“同样增强，有一致性”，不能混淆收益。
- 子波/相位等最好从同一地质模型重新渲染；若无可重渲染中间体，明确定义为后处理扰动，不能声称物理重合成。几何不变不代表可观测信息量不变，要限制严重破坏信号的增强。
- 最终 B0/B1/候选至少 seeds2026/2027/2028；A1 是否重复取决于差值大小和结论需要。
- 公开 Wu20、v2 test100、本地 Wu-style test100、legacy test110 统一冻结后评估。论文主表选源域与官方外部域，后两者作为补充，不夸大目标域数量。
- 加一个任务专用强基线和一个独立真实工区；真实工区必须先确认标注范围，按空间块隔离，重叠 patch 不跨分区。

## 6. 评估与“预估结果”的正确用法

现有观测：v2 历史 test MaxViT≈0.8326、UNet-L≈0.8355（后者只有56epoch）；官方 Wu20：MaxViT≈0.3370、UNet-L≈0.4830、UNet+attention≈0.4940。不能把不同 epoch/选择协议的数值当成新协议下必然复现的基线。

当前没有可信统计模型能预测新结构将达到多少 IoU。预注册以下工程目标，不视作预测、置信区间或投稿门槛：

- 域内：与同协议最佳强基线持平或提高，下降容忍上限暂设 0.005；争取绝对提升 0.005–0.010。以约 0.83 的历史水平仅作量级参考，即希望进入约 0.84 区间，不承诺实现。
- 外部：相对同协议表现最好的基线争取绝对提升 0.02–0.03。若基线仍约 0.483，目标约 0.50–0.51；只从原 MaxViT 的 0.337 提高但仍低于强 UNet，不算泛化目标完成。
- 困难结构：铲状/分支召回增加且精确率没有明显牺牲，并减少真实漏段；观察几何偏置是否造成错误连接。
- 资源：尽量参数增加<5%、实测推理耗时增加<15%，需实现后测量，不能提前当结果。

主指标 strict voxel IoU@0.5，辅以 AP、P/R、各类 IoU、正确的距离容差指标和固定错误可视化。AP 当前是直方图近似，应保留定义。标注/表面距离受体素间距影响，需明确单位；不能靠改变标签厚度制造优势。

报告多种子均值/标准差和每体配对差异，按独立体或工区块重采样。已有测试集不是盲测；最终确认集和真实数据不能用于模型选择。正常的失败结果包括：法向学得好但分割不变、域内提高但外部下降、召回提高但错误连接增多。
