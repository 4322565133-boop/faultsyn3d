## 2. 文献实际做法与可以借鉴的部分

### 2.1 thesis 中的去噪预训练论文

Mahzad & Bagheri，*Fault detection in seismic data using a true 3D global attention convolutional network with self-supervised denoising pretext training*，Scientific Reports，2026。

- 本地 PDF 第 7–10、19–24 页：先在新西兰 Taranaki 的 Kerry-3D、Opunake-3D、Kahu-3D 预训练，再用澳大利亚 Thebe 标签微调。**不是 Thebe 的“其他工区”。Thebe 是一个工区，不同切块不能自动视为不同采集域。**
- 加入标准差为局部 RMS 的 5%–30% 的高斯噪声，恢复原始野外数据。原始目标仍含现场噪声，不是干净真值；这种任务不能保证学会消除所有采集噪声。
- 64³ 窗口、stride=32；Thebe 先按 60%/40% 留出，再把前者按 70%/30% 分训练/验证。其轴命名及预处理与我们的协议不能假设完全一致。
- 微调同时包含分层学习率、逐步解冻和复合 loss，不是只换一个初始化。
- 第 31–34 页及 Table 3：基线验证 IoU 0.651，单独预训练及相应微调方案 0.681，注意力方案 0.703，全方案 0.744；全方案测试 IoU 0.698。**0.744 是验证，不是测试；预训练消融约 +3 个百分点，不是把 0.39 变成 0.74。**

我们与该文无预训练基线本来就有很大分差，必须先对齐区域、标签、阈值、拼接和指标汇总，不能把全部分差归于预训练。[原论文](https://doi.org/10.1038/s41598-026-54829-x)

### 2.2 补充：Swin-UNETR 自监督论文（原文已下载到本次报告目录）

Zhang et al.，*Improving Seismic Fault Recognition with Self-Supervised Pre-Training: A Study of 3D Transformer-Based with Multi-Scale Decoding and Fusion*，Remote Sensing，2024，16(5):922。

- 第 4 页：15 个私有工区无标签数据预训练；Thebe 900/200/703 空间划分。
- 第 9、13、16 页：SimMIM 使用模拟 16³ 大掩码；先切 256³ 母块，再随机裁 128³ 输入。**256³ 是母块，不是模型输入！** 推理 128³、stride64、重叠平均；预训练 300 轮、微调 100 轮。
- 第 13 页的 ODS/OIS 是跨阈值搜索的逐剖面 F1 汇总；不是固定阈值的整区微平均 IoU。
- Table 2：Swin-UNETR 的 ODS 0.840→整网 SimMIM 0.868，增益 2.8 个百分点；新模型无预训练 0.847，整网预训练 0.870。架构和预训练要分开验证。

论文支持域内自监督和整网预训练，不支持“所有 Transformer 都会大幅提升”。[原论文](https://doi.org/10.3390/rs16050922)

### 2.3 thesis 中的大规模 benchmark

Quesada et al.，IEEE Access 2025，DOI 10.1109/ACCESS.2025.3643616。本地 PDF 第 8–11、17 页。

它处理 2D 剖面，统一了标注厚度（骨架化后膨胀），Thebe 使用 400 张训练/100 张其他区域测试，并对阈值作处理。其分数不能直接和我们的原始三维标签比。第 11 页报告，在其设置中 Thebe 上表现最好的模型来自 Thebe 自身从零训练，FaultSeg3D/CRACKS 迁移可能退化。**预训练存在负迁移，不能视为必选增益。**[作者论文](https://arxiv.org/abs/2505.08585)；[作者代码](https://github.com/olivesgatech/large-bench-geo)

### 2.4 thesis 中其余相关论文

- *Fault Detection From a Large Perspective With Transformers*，TGRS 2024，第 5–7 页：使用合成 128³ 数据及两块 600³ 合成体，融合目标块周围 26 块的编码特征；真实 F3、Kerry3D 等主要用于展示。启示是增加**真实空间视野**，不只是给同一个 128³ 内部重复加注意力。
- *FaultSeg3D plus*，Geophysics 2024，第 6–7 页：重视训练分布与采样间隔，包含垂向重采样等实验。数据物理尺度、增强和 loss 都值得控制。
- 2023 R2SE-Unet compound-loss 文献主要是合成训练及真实应用，不能据其分数推出 Thebe 上同等表现。
- DoubleBlock-ViT 是 MRI 脑肿瘤模型，BraTS 的块状目标与断层薄面不同；它提供结构灵感，不提供 Thebe 预训练能成功的证据。

## 3. 立即采用的协议澄清，及待验证的微调

### 保留当前主协议

保留训练 [0,868)、验证 [900,1068)、测试 [1100,1803)、32 张缓冲、原始标签、信号支持掩膜、128³ 输入/64³ 中心计分、阈值 0.5 主指标。不要因为分数低重划测试集、只挑有断层区域或修改测试标签。测试历史结果已经被查看，今后如实称为已使用的固定测试集，不宣称从未接触。

完整验证 IoU 仍选择 checkpoint。论文另报 AP、P/R、验证集确定阈值后的结果；后者另列，不能替代主结果。若报告文献式 ODS/OIS，要标明阈值是否在测试上搜索、逐剖面汇总方式，不能当可部署固定阈值成绩。2-voxel 容差指标可作辅助，不能代替严格指标。

### 微调 A：先补诊断，不重训

新增 `train/diagnose_thebe_spatial.py`，只读取验证区域：

1. 选已有 best_fullval.pt 和 last.pt，各算 P/R、AP、0.05–0.95 阈值网格。
2. 单独统计没有正标签的核心块误报，以及需要补零上下文/内部区域的结果。
3. 保存每核心 TP/FP/FN 和坐标，用于后续定位漏检带、边界问题与固定剖面展示。

阈值网格计数已用 CPU 测试验证，包括恰好等于 0.5 的情况；尚未执行 GPU 完整诊断。诊断完若 AP 基本不变而最佳阈值改变，优先解释为校准问题；若 last 的 AP 与 IoU 一同变差，才更支持表征泛化退化。

再增加固定 96 个训练核心的无增强评估，位置由训练信号支持区确定。它与验证使用同一推理模式，区别于随机训练 loss；该训练探针尚未实装。

### 微调 B：取样做一个受控候选 S1

对第 47 轮前 384 个样本索引复现了原始窗口抽样（增强前）：48.44% 完全没有正标签，60.42% 正标签占比 <0.5%，中位数仅 0.00856%。这是一个有限抽样估计，不代表每轮都如此。

当前 Dice 对空标签窗口接近常数 1，梯度很小；这些窗口主要由 Focal 更新。背景对抑制误报必要，但几乎一半窗口不给断层形态监督，值得调整。

S1：每轮仍为 2400 块，50% 维持原均匀信号窗口取样，50% 从**训练区**含正标签的空间单元抽样。前景候选要求中心64³中有效正标签比例 ≥0.5%，避免正标签只出现在窗口边缘；先均匀选符合条件的空间单元，再在单元内随机选起点，避免按正体素数过度偏向大断层。保存抽样索引，所有模型复用。

不丢掉均匀分支的空块，不对验证/测试分层选块；先保持原 loss 和增强，仅改变取样。这个方案可能改善召回，也可能增加误报，要由验证 P/R/AP 判断，不能预先认定更好。取样改变后概率校准可能变动。

### 微调 C：loss 候选 L1，晚于取样实验

先不加 clDice/骨架/法向损失。Thebe 标注厚度和完整性与合成真值不同，不宜把人工标签当精确断层中面。

L0 是当前 `0.6 Dice_all_patches + 0.4 Focal_all_valid_voxels_per_patch`。

L1 只改 Dice 的归约：`0.6 mean(Dice_loss over foreground-containing patches) + 0.4 Focal_all_patches`。空标签块仍通过 Focal 学习背景，整批无正块时 Dice 项置零。DDP 下前景块计数与分子必须正确跨 rank 归约，不能每卡自行跳过后造成不一致权重。

L1 的目的在于提高前景形态梯度的有效占比，不保证一定优于 L0。先比较 S1+L0 与 S1+L1；不同时加入新的采样、噪声增强、Tversky、深监督和几何项。若后续只发现阈值偏移，优先做校准，不用 loss 堆叠掩盖。

## 4. 接下来最省试错的实验顺序

|顺序|实验|模型|决定什么|
|---|---|---|---|
|E0|已有 best/last 的完整验证诊断|UNet、MaxViT|校准、后期退化、背景误报与边界影响|
|E1|当前 context_both 原方案继续|正在运行的原型|先到相同进度比较，保留完整从零基线|
|E2|S1+L0，相同训练预算|先 MaxViT，再 UNet|取样是否真能改善学习|
|E3|仅当 E2 有效，再试 S1+L1|先 MaxViT|排除空块 Dice 稀释梯度的影响|
|E4|无预训练 / 去噪预训练 D / 掩码预训练 M|先 MaxViT 小规模筛查|检验预训练任务本身，而非预设 D 正确|
|E5|胜出的统一配方，架构×预训练 2×2|原 MaxViT、新模型|架构收益与预训练收益是否独立存在|
|E6|相同预训练和微调待遇的 UNet；3种子|最少必要对照|收益是否稳定，是否只是训练待遇不同|

筛查可以先跑 60 轮、学习率仍按 100 轮日程，和基线前 60 轮比较；正式最终比较完成相同 100 轮、2400 块/轮、batch8，共计划30000次更新。完整验证与主 checkpoint 选择保持每轮一次，预算一致。不续接第 47 轮训练好的权重来冒充从零结构对比。

实用晋级线（不是统计显著性，也不是预测）：完整验证 IoU 至少 +0.01，同时 AP 或固定召回下精度有所改善，且不靠明显的 P/R 单边交换。低于此幅度的探索先查种子波动，不继续堆模块。最终用相同种子 2026/2027/2028 报均值与标准差；空间置信区间不能把体素或相邻小块当独立样本。

## 5. 预训练如何做才公平、可执行

### 第一阶段：只用现有 Thebe 训练区，检验有没有收益

无标签预训练只读取 [0,868) 的地震振幅；不读取验证/测试/缓冲区域，也不因有无断层标签筛预训练样本。这是**同工区训练区自监督**，不能写成多工区预训练。利用验证或测试振幅进行预训练属于另一个目标域适应设置，需要独立声明，不能混入当前主实验。

- **D：去噪。** 信号区归一化后，加入 σ∈[0.05,0.30]×局部 RMS 的高斯噪声；重建原始野外信号，使用支持区 L1。保留原始振幅为目标，不用滤波后的“伪干净”地震作为未经验证真值。
- **M：掩码重建。** 128³ 输入，16³ 连续块掩码，初始比例50%；只在被遮住的有效体素计算 L1。整网编码器和解码器预训练，随后重置最后一个分割输出层。50% 是本项目预设候选，不是声称复刻了文献75%。
- 每个候选先预训练30轮×2400块=9000次更新，再同预算微调；只作筛查，不能等同文献15工区/300轮。新模型/UNet若纳入正式比较，也必须获得同样预训练数据与任务。
- 微调候选固定 encoder峰值学习率3e-5、decoder/head 1e-4，5轮warmup后cosine；这是预设起点而非已验证最优。先不再同时搜索逐步解冻。随机初始化组使用原来统一1e-4。
- 表征与微调配方的归因需补充“同一微调学习率组配置”的随机初始化对照；额外算力需报告，增加随机初始化的等总更新数/等GPU小时控制，避免仅把多训练30轮当预训练机制收益。

如果训练区自监督有可靠收益，再考虑 Kerry/Opunake/Kahu 等独立工区，先确认数据来源、权限、轴/采样间隔、是否与后续泛化测试重叠。不要先花大量时间下载多个工区来赌结果。

### 第二阶段：少标注条件验证价值

主结果仍保留100%训练标签；另设置10%/25%标签子集，检验“自监督是否提高标注效率”。子集按固定空间单元定义为嵌套集合，不是随机取10%高度重叠patch。SSL可用全部训练区振幅；监督 loss 只在选定标注单元内计算，其他位置是未知，不是背景。所有架构共用同一单元掩膜、种子和验证区。

不要只挑出现优势的标签比例。预先固定10/25/100三档；少标注实验不能替代100%主结果，更不能宣称它自然说明跨工区泛化。

## 6. 新模型方向：当前原型失败后，才进入下一结构

当前 Context-Grid 原型与原 MaxViT 都只看到同一个128³，解码器注意力可能只重复已有上下文，所以提升小并不奇怪。若公平训练后仍无稳定提升，建议转向**真实大视野、细节保持的双尺度 MaxViT**，而不是再给同一视野加门控层。

候选结构（尚未实现）：

1. 细分支输入原分辨率128³，沿用MaxViT层次编码，保留高分辨率卷积跳连。
2. 粗分支取同中心256³物理索引范围，抗混叠降采样为128³，用轻量编码器提取大范围地层上下文。
3. 对齐细块在粗视野中的坐标，在16³/32³特征层由细分支发出Q、粗分支提供K/V，做跨尺度grid融合；输出仍只解释目标块。
4. 不盲目放大全分辨率注意力。目标总参数约30–40M，但先实测4×11GB可运行性、FLOPs和时延；目标不是把网络做得越大越好。
5. 大视野窗口遇到训练/验证/测试边界，只能在各自划分内部取数据，越界补零与mask；不能读缓冲/邻接验证区来扩展训练上下文。

必要控制：原模型128；大视野+普通conv融合；大视野+grid融合；再叠加相同SSL。UNet也要有同输入信息量控制，否则改进可能只是看了更多数据。报告容量/算力，不能把40M对9.6M写成参数匹配。

如果同时做双尺度掩码预训练，必须先在全局坐标遮挡，再生成粗细两路；否则粗分支可能直接泄露细分支遮挡位置的答案。

大视野本身已有2024 TGRS先例，不能把“双分支+grid”直接宣称新颖。需要通过误差定位说明为什么跨尺度传递能区分连续断层与局部伪影，并与已有上下文方法比较。这个方向是待检验设计，不是确保TGRS接收的结论。
