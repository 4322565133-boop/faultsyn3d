## 2. 为什么换了很多模块还没有明确改善

目前能确认的是，多数改动增加/更换了特征处理方式，却仍在相同128³输入中工作，训练监督和推理口径也基本相同。它们并未获得块外信息。Context-Grid的“context”来自同一输入块深层特征，不是实际扩大输入视野。

不同候选同时改变参数量、预训练、冻结方式、浅层细节分支和训练长度，因此不能由这些结果推出“网格注意力不适合Thebe”或者“Thebe无法拉开模型差距”。能得出的工程决定是：这些版本目前没有提供足够证据，暂不继续扩展同类模块组合。

代码显示adapter先沿切片方向avg_pool，再预测跨切片残差；这可能在融合前丢失薄断层的位置信息，是需要消融的风险，不是已证明的根因。VSS-SAM使用冻结二维图像特征，它的预训练并没有学习Thebe成像特点；失败不能证明地震任务预训练无效。

基线验证P/R：UNet 0.594/0.507，MaxViT 0.613/0.527。adapter最好点0.497/0.610，召回改善伴随精确率损失。当前首要问题应是“恢复真实漏段，同时抑制新增背景响应”，不能只继续强化连通性。

训练对有效128³区域计算loss，验证只计中心64³；这种做法本身常见，但边缘低上下文预测可能分散优化预算。训练块的信号支持率、断层比例、深度和边界分布与完整验证是否不同，需要实际分层诊断。抽样审计发现很多空块，说明有优化空间，并不证明所有困难来自抽样。

## 3. 先做一次能决定方向的诊断

对UNet、原MaxViT、adapter的best_fullval做整验证区阈值曲线、AP、每核心TP/FP/FN，固定空间示例展示输入、GT和三个预测。另对固定训练窗口用eval模式比较同口径指标，区分拟合不足与训练—验证差距。

使用train/diagnose_thebe_spatial.py。本次将它兼容SpatialThebe新增的第四返回值；仅语法检查通过，GPU诊断尚未执行。不要把脚本存在当成诊断已完成。

判断依据：

- 如果adapter AP较好但0.5下P低，应先检验概率校准和同预算训练；阈值只在验证选择，对所有模型相同处理，0.5主表保留。
- 如果错误主要是标签附近1—2体素的位置/厚度偏差，下一结构实验优先32³→64³的浅层引导动态对齐；代码已有dyn_upsample3d候选，需检查其与本轮协议兼容和历史训练记录，避免重复发明。
- 如果主要是超出局部位置容差的整段漏检、噪声区伪断层，优先真正扩大上下文，方案见下一节。
- 如果固定训练集也拟合不好，先核查监督、loss梯度及训练配置，暂缓新架构。

平方分母Dice、Tversky或MD loss不能自动视作修复。现有loss用FP32；空正例块的线性Dice几乎常数、背景主要由Focal学习，这是定义结果，不是已证实数值错误。任何新loss先给UNet和MaxViT同样的对照，不用历史旧配方弱基线宣称结构收益。

## 4. 最值得保留的现成候选：adapter

先将这一版作为唯一保留候选，按原随机状态/优化器/100轮日程续训到至少47轮做中期诊断；若有效再完成100轮。与基线同轮轨迹比较，不只看各自峰值。停止规则必须预先定义；不能每换一个模型就按前几轮涨幅反复砍掉。

最终如它有收益，再做“二维预训练编码器＋3D解码器，无adapter”的对照，区分预训练、解码器与adapter的作用。冻结/微调配置和学习率选择预算要明确。能超过UNet但不能超过原MaxViT时，只能记为有效轻量替代，不能宣称新的最高精度模型。

FG抽样作为独立训练因素。完成现有5轮探针只解决启动和数值问题；若继续评估采样作用，需要UNet和原MaxViT共享足够训练预算、同一loss与同一取样规则。不要一边换抽样一边换架构或loss。

## 5. 下一种结构只保留一个：细节分支＋实际块外上下文的MaxViT

若诊断支持长段漏检/噪声混淆，建议从原3D MaxViT基线开发双视野候选。目标是用更大区域判断一个局部不连续是否属于持续的断层，并保留原分辨率定位。

输入：同中心的fine128³和context256³。context先低通下采样到128³，用轻量上下文编码器得到低分辨率特征；fine保持原MaxViT、全分辨率skip和原分割头。上下文特征按实际坐标映射到fine区域，在32³/16³阶段通过cross-attention融合，输出仍只针对fine128³。第一版只加16³一处融合，不同时改多个解码阶段。

context256的中央128只占context下采样输入的中央64，因此不能将两分支整个特征图直接同尺寸拼接。当作整片平移/缩放的坐标映射实现；需核查token中心、有效支持区与补零掩码。低通下采样不能代替fine细节。

这与以前Context-Grid的区别是读取实际块外地震信号。上下文分支、投影与融合以不超过原40.16M参数约15%的新增预算作设计目标，实际测量后再决定；不承诺该目标必然可达，也不承诺一定涨分。

Thebe已有连续体，适合构造该输入；现有独立128³合成体不能拼成真实256³邻域。1000体保持原用途：合成分支诊断、普通单视野模型比较或同待遇预训练。双视野模型的合成实验若需要真实上下文，必须来自连续母体，不能用复制/拼贴块伪造地质连续性。

更大输入要求重新冻结训练、验证、测试的context读取规则。维持各区域边界；context不得越过分区，越界用同样的信号无效补零。边界有效上下文少，单独报告边界/内部结果。此前32缓冲并不允许跨分区取256³上下文。

最少需要的结构对照：原MaxViT；fine＋context卷积融合；fine＋context注意力融合；UNet获得同样context输入和合理融合预算。否则收益只能说明“更多输入有用”，不能说明MaxViT融合设计更合适。另做上下文仅保留中央fine区域、块外归零的控制，检查是否确实使用块外信息。

“Fault Detection From a Large Perspective With Transformers”（TGRS2024，DOI10.1109/TGRS.2024.3470536）已经利用26个邻块扩展上下文。双视野本身不是首创；投稿贡献要由更省资源的三维坐标对齐、局部精度与长段覆盖改善，以及匹配输入/预算的机制消融支持。

若诊断显示主要是定位偏差，则优先动态对齐，双视野降级候选。一次只实现一个假设，避免把两个网络改动一起训练后无法归因。

## 6. Loss与投稿结论

第一轮结构控制统一现有Dice＋Focal。结构有效后，若存在同一体素因窗口位置而变化的预测，再单独加重叠区域概率一致性：同一区域两个视图只在共同有效体素比较，不在未标注区强加“都为背景”；与相同双视图但无一致性的控制比较，记入额外计算量。

目前不建议加“全体只有一个连通分量”“禁止分支”的全局拓扑loss。我们的合成数据包含真实花状/马尾分支，这类目标会惩罚正确地质结构。MD Loss（TGRS2022，DOI10.1109/TGRS.2022.3196810）针对稀疏标注与假负例，需要先核实Thebe标签问题，不能直接假设当前FP都是漏标。

已有历史分数是参考，不是新的公平协议目标。新候选需要在完整验证中超过同协议原MaxViT，且AP、P/R及固定错误图支持解释；最终主要对比至少3种子，测试只在方案冻结后评价。可将+0.01验证IoU作为是否值得投入多种子预算的工程目标，不是效果预测或TGRS录用门槛。

当前没有依据保证达到0.45、0.50或文献不同协议中的0.7。若改抽样/增强能提高所有模型，应先更新强基线，再评价结构的额外收益。仅超过旧baseline不够支撑新模型贡献。

立即执行顺序：完成现有探针的运行检查 → best权重整验证诊断 → adapter同预算续训 → 按错误类型选择动态对齐或双视野一种 → 同输入控制 → 有收益后loss单因素与多种子确认。当前不再开DoubleBlock/SAM/其他主干的广泛扫模型队列。
