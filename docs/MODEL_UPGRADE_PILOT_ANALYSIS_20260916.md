# 20轮继续训练结果分析与下一步决定

日期：2026-09-16。两组训练、最终测试和图集均已完成；本轮为单种子的继续训练预实验。

## 1. 结果与结论

| 项目 | 历史基线 | 同预算继续训练基线 | 模块＋复合loss |
|---|---:|---:|---:|
| Test IoU | 0.832587 | 0.832540 | 0.832400 |
| Dice | 0.908647 | 0.908619 | 0.908535 |
| Precision | 0.911266 | 0.911581 | 0.909790 |
| Recall | 0.906042 | 0.905676 | 0.907284 |
| AP（2000分箱近似） | 0.956010 | 0.955778 | 0.955811 |

相对同预算基线：IoU降低0.0140个百分点，Precision降低0.1791个百分点，Recall提高0.1608个百分点。AP只增加约0.0033个百分点，不构成有说服力的提升。

结论：本轮没有证据支持完整改进方案优于基线。差异很小，单种子不能判定统计显著优劣；也不能把几乎持平说成创新成功。召回上升、精度下降提示主要观察到检出取舍变化，不能据此证明薄面定位或连通性改善。

两组最佳验证checkpoint均在第18轮：baseline Val IoU=0.821256，combined=0.821057。它们的训练分割损失曲线几乎重合。test.json中的loss来自公共评价函数，不是训练的复合loss，不能拿其下降证明复合loss更好。

五类Test IoU的相对变化均非常小；不据测试类分数重新调权重或挑选有利类别。

## 2. 验证集机制检查（没有再用测试集挑选方案）

在combined第18轮权重上，保持其他权重不变，只在推理时关闭D2S，遍历100个验证体：

- 开启：Val IoU=0.82105106。
- 关闭：Val IoU=0.82104447。
- 差值：0.00000659，即约0.000659个百分点，接近极小的数值/预测差异。
- 改变二值预测的体素比例约0.00201%。
- 平均概率绝对变化约0.00002037。
- fusion32输出相对浅层输入的L2变化平均0.234%。
- fusion64对应变化平均0.307%。

这说明本轮新模块对预测的实际作用很弱。关闭已训练模块的推理干预不是独立训练消融，不能直接据此断言模块从零训练也无效，也不能证明差异全部来自loss。

权重检查：门控的有效乘法调节上限约0.87%和0.96%；上下文残差系数约0.00204和-0.00341。初始为严格恒等、旧主干已收敛、短期低学习率继续训练，是弱作用的合理解释，但尚未证明因果。

两组还在同一epoch14/step98经历过AMP溢出，修复后都跳过一次更新，均完成1999次实际更新。该现象不是“新loss独有故障”的证据。异常已显式记录，不能隐瞒成完全无跳步。

参数仅新增68,938（约0.172%），但平均每轮约60.44秒，对照约53.69秒，增加约12.6%。参数少不代表高分辨率融合没有计算/显存成本；目前没有精度收益来证明该开销值得保留。

## 3. 下一步明确决定

结束继续训练路线，不再往当前历史checkpoint上追加更多轮数尝试刷过0.833。保留当前数据、记录、模型和图集作为负结果预实验。

第一阶段只做两组，从随机初始化开始：

A. 强化MaxViT基线B0（固定full_res_skip=True、img_size=128、drop_path=.2）。
B. B0＋D2S，仅改网络，不加入profile/trace。

两组数据800/100/100不变；四卡DDP，每卡batch2，全局batch8；同一200轮预算、随机种子2026、AdamW lr=1e-4、wd=.01，10轮warmup后cosine至1e-7；统一FP32 Dice/Focal。这里的参数是拟冻结协议，不代表最优值。

D2S从零训练时不再要求精确复现旧模型的输出，拟把上下文残差初始有效系数设为0.1、门控乘法调节上限初始设为0.1，让新增分支从早期获得有效梯度。保持原浅层残差通路。这是待验证的初始化设计，不能通过强行放大系数就宣称模块有效。

实现时需要：

1. 在训练入口加入明确的随机初始化模式，而非给--init传入不存在的路径。
2. 两组共享主干/解码器随机初始化种子与数据顺序；只新增D2S参数。
3. 几何损失关闭时可跳过几何缓存读取和采样，两组使用完全一致的输入增强。
4. 记录D2S系数、特征改变量、梯度量级和训练成本，避免再次只看模块“挂上了”。
5. 验证集选模，训练曲线只作诊断；不要基于训练早期的一点波动任意延长某组预算。正式对比只在冻结训练后评价测试。

第二阶段根据第一阶段结果决定：

- 网络有稳定验证收益：再分别加入profile、trace，最后有需要才组合。
- 网络仍与简单skip基本持平或更差：先修改/删减D2S，不立即堆更多模块，也不直接进入Thebe。
- 损失只有召回提高、精确率下降且IoU/PR整体不改善：不保留为有效创新。
- 核心结果出现收益后，再补多种子与普通Attention Gate/同预算融合对照，防止把额外参数或偶然性算成创新。

不能保证从零训练一定改善。该阶段的意义是回答“结构有没有价值”，而不是为已有简历数字寻找实验设置。
