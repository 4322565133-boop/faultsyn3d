# 双视野之外：沿断层薄面选择上下文的候选方案

日期：2026-09-18。状态：文献与模型设计建议，未实现、未训练。未改变当前进程。本文细化THEBE_REDIRECT_AFTER_NEW_PILOTS_20260918.md中的双视野候选，不将设计当成已证明创新。

## 研究问题

邻域中既有同一断层的延续，也有邻近断层、连续反射层与噪声。增加上下文可能帮助漏段恢复，也可能增加误报或错误连接。研究假设为：在相同上下文输入和采样预算下，依据局部薄面几何选择证据，比一般稀疏三维采样更有效。

当前adapter最好验证P/R约0.497/0.610、原MaxViT约0.613/0.527，这支持同时检查召回与误报的需求；它还不能证明误报来自上下文污染。开发前需验证错误图与PR/AP。

本轮读到CoTr完整方法；DSCNet和其余机制参考的内容用于候选设计，不将医疗指标或优化配置搬作Thebe结果预期。以上检索不构成穷尽的新颖性检索。

## 建议的主候选

工作名：Surface-guided Context MaxViT。名字只用于代码/讨论。

输入为同中心fine128³和context256³。fine保留原3D MaxViT编码器、全分辨率浅层分支与卷积解码器；context先抗混叠下采样到128³，经轻量3D卷积生成上下文特征。首版仅在fine16³阶段加一个稀疏跨视野模块，避免重做整套网络。

fine中的query映射到context真实坐标，预测一个局部方向框架t1,t2,n。优先采样沿两个切向的点，另外保留少量不受面方向限制的采样点：

```text
fine128 -> 原MaxViT -> fine16特征 ---------------------------> 原解码器 -> 分割
                             |                                ^
                             -> query/局部面方向 -> 采样/融合 --|
context256 -> 低通下采样128 -> 轻量3D编码 -> context特征 --------|
```

面内点的一种参数化为p_k = map(q) + a_k*t1 + b_k*t2 + c_k*n；a/b允许较大跨度，c为有限面外修正。位置/尺度统一在明确的原始采样坐标中定义，不能将两分支相同feature索引当成相同地下位置。可从每query总共12点（8面内、4自由）的工程起点开始，实际点数与通道预算需测量后冻结。

方向头、采样位移与attention权重均由输入特征预测。训练GT不能作为attention输入，推理不读取GT方向。CoTr式权重预测或采样后的QK权重是两种可行版本，首版只固定其中一种，不因命名为attention就混用定义。

限制单一平面跨度，允许面外修正和自由采样；强弯曲面不可能由一个无限延伸的切平面代表。若交汇处单面明显失败，再考虑多方向混合；不在第一轮同时加入多面、复杂loss、点细化与预训练。

attention学习抑制不匹配的外围特征；可以加入由local/context特征共同预测的融合门，但它只是候选机制，不称“可信度已校准”。不将融合门固定为原预测的前景概率，否则原模型预测为背景的真实漏段可能始终得不到帮助。门输出、梯度、采样点和实际块外占比需要记录，避免新增路径被关闭却被误解为几何假设无效。

## 方向学习如何落地

第一阶段方向/采样由分割loss端到端学习，不新增Thebe物理法向真值。无辅助监督时它只是学习到的方向，不能提前称其为真实断层法向。

可利用现有1000体的逐实例曲面独立核查方向、弯曲与交汇处理，甚至作几何辅助预训练；若引入这种额外信息，普通deformable基线也要有同样辅助任务，区分额外监督与采样机制。此前geometry_model_upgrade_v1是标签局部PCA缓存，不等于最终曲面的精确法向，不能沿用成真值。

Thebe标签局部PCA只能构造方向代理；厚度、缺口、边界和多面交汇使它不可靠。如后续使用，应只监督明确的单面区域，歧义掩码仅用于方向loss，不删除主分割标签。地震反射层法向与断层面法向不同，不能把结构张量测得的层理方向直接用作断层法向。

现有独立128³合成体没有真实块外邻域，不能拼成context256。合成集用于单视野诊断、局部几何核查或所有模型相同待遇的预训练；Thebe负责双视野量化。双视野预训练若需要连续母体，应独立安排数据准备，不把它设为首版必要前置。

## 最小实验与停止扩展的条件

1. A：原单视野MaxViT。
2. B：相同fine/context输入、普通自由3D可变形采样；点数、上下文编码器、投影、预算与C尽量匹配。
3. C：B改为面引导采样；不同时改loss与训练配方。
4. 若C优于B，再比较固定方向面采样、预测方向面采样及去掉自由点的版本，检验方向适配与交汇处理。
5. 投稿主要对比还需同双视野输入的强UNet控制与简单卷积融合；所有模型给合理、相同预算的验证调参。普通deformable是机制主对照，UNet/MaxViT是任务主对照。

若B>A但C≈B，证据支持大视野/稀疏采样，不能宣称薄面引导有独立贡献。若C只提高R但明显降低P，继续检查干扰与错误连接，不将连续性视觉效果当成精度提升。若采样几乎总在fine范围内，不宣称块外证据起作用。

块外置零等消融可能引入分布变化。可先做推理敏感性检查；作为主要因果证据还需同配方重新训练中央信息控制，且两组上下文掩码/归一化定义一致。

结构首轮沿用统一Dice＋Focal，当前FG抽样若后续成为正式配方，同样给A/B/C和UNet。先确认基础监督与模型训练充分。结构有效后再研究重叠窗口同体素的一致性或点细化；这些机制单独消融，记入计算量。

重要指标为严格IoU@0.5、AP、P/R、距离容差和固定剖面图。真实断层连通性或实例错误连接没有完整实例GT时，仅作明确定义的代理/定性分析，不能凭二值标签给出物理拓扑真值结论。

## 26邻块比较和公平协议

26个不重叠128块加中央块构成384³外包区域；我们的context256覆盖较小，不能称相同上下文预算。若与该论文实现直接比较，应统一FOV，或明确给出精度—计算—FOV曲线。不能将其文献F1与我们的Thebe严格IoU直接并排排名。

context不得读取其他划分数据，超出本分区用无效补零；记录上下文有效率，分别检查内部与边界。Thebe的时间/深度采样与水平间距不同，128³只是索引立方体；在缺乏速度与物理尺度信息时，几何限制描述为采样坐标中的形状先验，不称物理曲率或真实距离。

最终判断需要同预算完整训练与多种子，不承诺必然提高IoU或保证TGRS录用。最值得检验的潜在贡献是：针对薄曲面选择相关块外证据，在同输入、同稀疏点预算下同时改善漏检与误报。它与以前仅在原block attention中加入法向偏置的方案不同，但两者都需要与既有几何引导方法明确比较。
