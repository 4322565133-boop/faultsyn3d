## 2. 研究问题及拟验证假设

更准确的问题表述：三维地震断层是稀疏薄曲面，受低错距、复杂交汇和地震纹理干扰，预测容易出现厚度偏差、误连接、局部缺口和背景误报。

拟验证的两个假设：
H1：深层到浅层的多尺度语义门控，能减少无关浅层特征进入解码器，同时保留薄断层细节。
H2：利用合成曲面可获得的法向，以及断层在非掠切剖面上的迹线连通性监督，能改善定位、方向和连续性。

不能预设改进模型一定超过 U-Net。验证失败时应修改或放弃假设，不按简历数字倒推实验。

## 3. 必须纠正的概念与基线命名

### 3.1 三维薄曲面不是三维细管

断层在二维剖面上是线，在三维中通常是面。clDice 原工作主要针对管状/线状网络，不应不加论证地把三维断层面压缩成一条中心线。

第一版可采用多视角二维迹线 soft-clDice，作为辅助连通性监督，并保留三维分割主损失。它不能保证整个三维断层网络拓扑正确。更贴切的命名是“多视角迹线连通性与曲面法向监督”。

参考：[clDice 原论文](https://arxiv.org/abs/2003.07311)。

### 3.2 当前模型不是原版 MaxViT-UNet 的完整复现

本地模型是 timm_3d MaxViT 编码器与 DoubleConv3D 解码器。2023/2024 MaxViT-UNet 原文的混合解码器还包含多轴注意力，不能自动把本地卷积解码器版本命名为该论文的原版。

建议基线命名：MaxViT-Encoder–ConvDecoder-3D，并记录具体 timm_3d 版本、backbone 名称、各尺度形状和注意力窗口。

参考：[MaxViT](https://arxiv.org/abs/2204.01697)、[MaxViT-UNet](https://arxiv.org/abs/2305.08396)。不能依据这些医学/通用视觉论文称当前实现为三维断层领域 SOTA。

## 4. 数据与几何监督：保留现有 1000 体，建立派生缓存

保持 v2 seismic、labels、manifest 不变。新增独立的 geometry_targets_v2 缓存目录，保存其派生算法版本和原数据哈希。

第一版需要：
- normal_gt：三通道单位曲面法向，明确通道为全局 x/y/z。
- normal_valid：法向监督有效掩膜。
- 可选 junction_mask：多曲面近邻交汇区域，供法向屏蔽和交汇评价。
- 原有 labels：完整三维分割目标。

从 surfaces/metadata 重建曲面，用局部曲面导数或三角片叉积计算法向，再按最近曲面向窄带体素赋值。不能用整条弯曲断层的参考平面法向替代局部曲面法向。

重要细节：
1. 交汇处存在多个有效法向，第一版将这些位置从单法向损失中屏蔽。不要把 instances 中后写覆盖的编号误当成唯一几何方向证据。
2. 有限边界、NaN 邻域及病态局部导数要屏蔽。
3. 法向是无向轴，n 与 -n 等价。
4. 翻转/交换轴增强必须同步变换法向。一般坐标变换 x'=A x 时，法向按 A 的逆转置变换再归一化；平移不影响方向。
5. 体数组顺序是 z/y/x，几何点是 x/y/z，必须有明确的往返测试。
6. v2 首先采用索引空间几何；真实资料的水平距离与垂向时间不能未经尺度/速度处理就当作相同物理单位，不能把索引空间方向直接称为物理倾角。

无需为了增加辅助监督而重新生成全部地震体。单独的 confidence 仍是位移代理量，第一版不把它作为训练权重。

## 5. Geometry-aware Compound Loss 的第一版实现

建议从三部分开始：

    L = L_seg + lambda_trace * L_trace + lambda_normal * L_normal
    L_seg = L_Dice + L_BCE

主分割损失先固定成公平基线，不同时更换 focal、Tversky、困难负样本挖掘等多个因素。

### 5.1 迹线连通性项

从三维预测概率和标签抽取少量 axial/inline/crossline 剖面，对适合表现为窄迹线的剖面计算二维 soft-clDice，再求均值。

可微 soft-skeleton 由概率图的软形态学运算得到；不能先阈值化再骨架化后作为可微训练损失。目标骨架可以预计算或用相同算子生成。

对每个有效剖面：
    Tprec = sum(S(p) * y) / (sum(S(p)) + eps)
    Tsens = sum(S(y) * p) / (sum(S(y)) + eps)
    L_trace = 1 - 2*Tprec*Tsens / (Tprec + Tsens + eps)

对双方均空的剖面跳过该项，仍由 L_seg 处理背景。处理其他空集合情况，避免 NaN。初始可以每个方向抽取少量剖面，限制算力成本。

不要在与断层近乎平行、产生宽面状足迹的剖面上盲目应用细线先验。利用 GT 局部法向与切片法向的夹角进行剖面/窗口适用性筛选，并记录采样规则。避免用零散像素硬掩膜制造新的人工迹线断点。

第一版应把该项当作实验假设：它可能改善迹线，也可能误罚复杂交汇。必须同时检查三维错误连接和缺口，不能仅报告二维 clDice 改善。

### 5.2 法向辅助监督

从共享高分辨率解码特征增加三通道输出头，得到归一化的预测法向 n_hat：

    L_normal = sum(M * (1 - abs(dot(n_hat, n_gt)))) / (sum(M) + eps)

M 为有效法向掩膜。先在背景、交汇及边界不稳定位置关闭该项。全空掩膜时返回零。

这一版本是共享特征上的几何辅助任务，不是对最终二值曲面的严格法向保证。还应检查移除辅助头后分割的实际几何表现；只有法向头变好不能证明分割也变好。

不要直接把预测概率 p 的梯度在断层中心处归一化为法向：薄面概率在中心形成脊，梯度可能接近零。若以后使用距离场，应明确使用到真实中间曲面的距离，并处理无符号距离在曲面上的不可微点和交汇歧义。

### 5.3 权重与训练次序

可将 lambda_trace=0.1、lambda_normal=0.05 作为首轮试验起点，而非推荐最优值。先分别记录损失数值与梯度量级，再用验证集调整。开始若干轮只训练主分割损失，再逐步增加辅助项，减少随机初始预测的骨架噪声。

先做单独 trace、单独 normal，再组合。若 normal 只增加计算不改善分割，应保留负结果并删除该项，而非仅展示辅助任务指标。

## 6. Deep-to-Shallow 跨尺度融合的第一版实现

现有编码器输出 E0...E4，对应步长 2、4、8、16、32。先实际打印并记录空间形状与通道，不仅依赖注释。

对每个待融合层 l：
1. 通过 1×1×1 卷积将多个更深层 E_j 投影到统一通道数，例如 32 或 64。
2. 三线性上采样到 E_l 的空间分辨率。
3. 对齐后加权融合得到 G_l，权重可由可学习的尺度权重或输入相关权重产生。
4. 联合浅层特征、G_l 和上一层解码特征计算门控 A_l。
5. 使用门控后的浅层特征参与解码，同时保留深层融合特征。

示意公式：
    G_l = sum_{j>l} a_lj * Up(P_j(E_j)),  sum_j a_lj = 1
    A_l = sigmoid(Conv3D(concat(P_l(E_l), G_l, Up(D_{l+1}))))
    S_l = [epsilon + (1-epsilon)*A_l] * P_l(E_l)
    D_l = Block(concat(Up(D_{l+1}), S_l, G_l))

epsilon 可先试 0.1，防止深层门控过早完全抹掉浅层微弱断层。它是待调参数，不是固定正确常数。初始版本优先用卷积门控，避免在完整 128³ 分辨率做全 token cross-attention。

只在一两个浅层先试，再扩展到所有尺度，观察显存和薄面定位是否获益。full_res_skip 的启用条件必须在消融中固定，不能同时加入该分支又把全部增益归因于 D2S。

门控示意图只能说明模块结构。“抑制噪声传递”需要额外实验证据：同一几何和背景结构的配对噪声扰动、固定召回下的误报比较、薄分支召回，以及门控/特征响应变化。地震反射层理不是纯噪声，高频信息也可能含断层细节；不能预设所有浅层高频都应该被删除。

已有 Attention U-Net 就使用语义引导的注意力门控，因此“深层引导浅层”本身不是新概念。需检验多深层联合、三维薄面适配、几何监督与融合的具体组合是否带来区别和可复查作用。
参考：[Attention U-Net](https://arxiv.org/abs/1804.03999)。

## 7. 消融与公平比较

首先冻结一个稳定的 MaxViT 分割基线：输入尺寸、实际注意力窗口、全分辨率分支、drop path、解码器、训练流程均记录。若对现有基线做工程修正，要单独报告原配置与修正配置，不把工程修正藏入创新增益。

核心四组：

| 组 | D2S | trace+normal 几何损失 |
|---|---|---|
| M0 | 无 | 无 |
| M1 | 有 | 无 |
| M2 | 无 | 有 |
| M3 | 有 | 有 |

接着拆开 trace 与 normal；资源允许时做 D2S、trace、normal 的 2×2×2 八组实验。至少比较一个普通 Attention Gate 与所提 D2S，必要时增加参数量接近的卷积融合对照，判断增益是不是仅来自额外参数。

正式对比包含 U-Net、ResNet50-UNet、明确命名的 MaxViT 基线和最终模型。模型在相同数据划分与合理、可说明的调参预算下比较；不能故意使用训练不足的基线。

探索可先用单种子；最终主要结果建议至少三个训练种子，报告均值与波动，必要时按完整体进行配对 bootstrap。不要把每个体内的数百万相关体素当作独立统计样本。

IoU、Dice/F1、Precision、Recall、PR 曲线/AUC、各类别结果、薄面距离容差评价与连接/误连接诊断一起报告。把分割厚度误差、位置偏移和真正缺口分开。F1 与 Dice 在当前二值全局计数口径下是同一指标，不当作两条独立证据。

现有测试集已经查看过。后续选择结构和超参数仍使用验证集；如果反复根据原测试成绩选择设计，应为最终确认另设独立、冻结的测试集，并明确区分开发与最终测试结果。保持原 1000 体不变，新增测试数据采用独立目录/种子。

## 8. 跨域与真实资料

先建立合成域外测试：改变训练范围之外的角度、曲率、噪声、主频或树模板；每个因素与测试域定义清楚。仅换随机种子属于同分布新样本，不足以证明跨域。

再获得真实三维地震体。FaultSeg3D 原作者资料列有 F3、Kerry-3D 等现场案例，可以作为寻找数据的入口；下载可用性、数据范围、授权与断层标注需要逐项确认。地层相标签不等于断层标签。
参考：[FaultSeg3D 作者仓库](https://github.com/xinwucwp/faultSeg)。

没有真实断层 GT 时，只能做有边界的定性和解释者复核；不能由预测图计算真实 IoU/F1。有标注后再做独立定量评价，并区分零样本迁移与真实数据微调。多个调查区的划分不能由同一大体相邻切片随机拆分替代。

“工业级鲁棒性”还需要大体滑窗拼接、采样变化、运行时间、内存、异常输入等证据，不能用单个小体预测图支撑。

## 9. 建议代码落点与实施顺序

以下为建议新增文件，尚未由本方案实现：
- scripts/build_geometry_targets.py：从冻结曲面建立法向、有效掩膜等派生目标。
- train/geometry_dataset.py 或现加载器的受控扩展：同步读取和增强几何目标。
- losses/trace_connectivity.py：多视角 soft-clDice。
- losses/normal_consistency.py：无向法向辅助损失。
- losses/geometry_compound.py：损失组合、权重和 warmup。
- models/d2s_fusion3d.py：多深层语义门控。
- models/maxvit_geometry3d.py：独立组合模型入口，保留现有基线。
- qc/evaluate_fault_geometry.py：定位、厚度、缺口和误连接的额外诊断。
- configs/experiments/：冻结各组实验配置。

顺序：
1. 汇总当前已有训练和测试账本，识别已完成/正在运行/不同训练配方。
2. 在验证集上检查 MaxViT 误报与薄面定位，冻结基线工程设置。
3. 独立实现并验证 D2S，在主分割损失下试验。
4. 建立几何目标，并检查法向的翻转、轴交换、交汇屏蔽。
5. 分别加入 trace、normal，再组合。
6. 做核心消融、多种子复查、域外与真实资料验证。
7. 根据实际结果写论文和简历，不先固定提升幅度。

## 10. 简历文字与可证实成果的对应

目前可以确认：完成 1000 个带体素标签的合成体、存在 v2 三基线测试记录、已有部分 MaxViT 工程设置探索。

截图中的中心线/方向损失、D2S 模块、固定提升幅度、真实数据迁移和投稿状态，需要各自对应源代码、实验记录、真实资料或投稿凭据。本文不把它们视为已经证实的结果。

特别注意数学口径：当前全局二值计数下，F1 = 2*IoU/(1+IoU)。若以现有 U-Net 的 71.71% IoU 为基准，提高 14 个百分点到约 85.71%，对应 F1 约 92.30%，比原 83.52% 高约 8.78 个百分点，并非 16 个百分点。不同宏平均口径可能不满足均值之间的该关系，但必须明确，不能混用。

在实验完成前，可采用研究进行式表述：
“构建 1000 个具有体素级断层标签的三维合成地震体，完成 U-Net、ResNet50-UNet 和 MaxViT 编码器分割网络的初步比较；针对薄断层定位与连接问题，研究深层语义引导的跨尺度融合及迹线连通性—曲面法向联合监督，并通过模块消融和域外测试验证其作用。”

与 TGRS 目标相对应的贡献应是具体、可验证的方法和地震资料证据。堆叠已有注意力与损失函数、仅在单一合成分布上获得高分，都不能直接证明创新性或保证录用。
