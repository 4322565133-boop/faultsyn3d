## 0. 最新任务与范围

用户明确：论文核心是模型升级，尽量对应简历中的 Cross-Scale Feature Enhancement、Deep-to-Shallow skip connection、Geometry-aware Compound Loss。减少冗余泛化实验。

本方案收敛为：

> 在已有 MaxViT 三维编码解码网络上，用多尺度深层语义引导浅层跳接；通过二维迹线连通性和沿曲面法向的概率剖面约束，兼顾薄断层的连续检出与准确定位。

主要贡献组织为两项：

1. 网络：跨尺度 Deep-to-Shallow 融合，一个整体模块，内部可消融“多尺度上下文”和“残差语义门控”。
2. 损失：基础分割 + 迹线连通性 + 法向剖面定位，直接作用于分割预测。

实验主线：合成数据集与 Thebe 各自监督训练和独立空间测试；合成集做主要消融，Thebe 做精简确认。暂不安排完整的合成→真实零样本、预训练→微调、少样本、多个 OOD 数据集矩阵。

## 2. 简历叙述如何对应可实现方法

| 简历方向 | 本方案中的实现 | 可以声称的范围 |
|---|---|---|
| Cross-Scale Feature Enhancement | 多个深层特征对齐，在不同空间位置选择尺度 | 待实验验证能否改善不同尺度断层 |
| Deep-to-Shallow skip connection | 深层上下文与解码特征共同调节浅层 skip，保留残差 | 待验证能否减少背景误报，同时保留弱分支 |
| Geometry-aware Compound Loss | L_seg + L_trace + L_profile | 三项分别承担检出、迹线连续性、法向定位职责 |
| 中心线拓扑约束 | 二维剖面上断层迹线的 soft-clDice | 不将三维薄曲面强行压成一条中心线，不保证完整三维拓扑 |
| 方向约束 | 沿标签估计法向比较预测与标签的概率剖面 | 准确名称是“法向剖面定位约束”，不是直接预测倾角/走向 |
| 抑制背景噪声向解码器传递 | 在相同召回或完整 PR 曲线下检查 FP、错误图 | 门控热图漂亮不能单独证明抑噪 |
| 模型对比和消融 | 同配方基线、结构消融、损失消融、少量机制对照 | 增益、投稿状态和结论必须来自真实记录 |

如果简历必须保留“方向约束”这个词，面试中解释为沿局部法向的剖面约束；更推荐最终文字写“多视角迹线连通性与法向定位约束”。不要把它解释成已经完成三维地质方向预测。已有简历中的具体提升数值不能成为实验的预设目标。

## 3. 网络结构：两个可开关部分组成一个 D2S 模块

### 3.1 先冻结强化基线 B0

以现有 all3 结构为起点：full_res_skip=True、img_size=128、drop_path_rate=0.2；后者仅是延续已有配置，并非认定最优。所有结构消融使用相同配置，正式消融前如调整需统一冻结。

128³ 输入下编码器预期特征：

| 特征 | 空间尺寸 | 通道 |
|---|---|---:|
| E0 | 64³ | 64 |
| E1 | 32³ | 64 |
| E2 | 16³ | 128 |
| E3 | 8³ | 256 |
| E4 | 4³ | 512 |

实施时打印实际张量确认，不只依赖注释。完整分辨率分支保留；原编码器和4³/8³/16³处解码流程先不改。只在32³、64³两个 skip 位置加入新模块，控制显存和归因。

### 3.2 A：输入相关的跨尺度上下文

32³处选 E2/E3/E4；64³处选 E1/E2/E3。每个深层特征先用1×1×1卷积投影至32通道，再三线性上采样到目标大小。统一 align_corners=False。

```text
H_lj = Resize(Proj32(E_j), size(E_l))
w_l  = softmax_scale(Conv1x1(concat_j H_lj))
G_l  = sum_j w_lj * H_lj
S_l  = E_l + eta_l * R_l(G_l)             # A-only
```

w 在每个空间位置沿尺度维归一化，而非沿全部体素归一化。R_l 将32通道恢复至 E_l 通道。eta 是可学习残差系数，初始化近零，例如0.01；记录其变化，避免没有实际使用该分支。

它回答“这一位置需要较细节还是较大范围的深层上下文”。权重不自动具有地质含义，需通过对照验证。

### 3.3 B：保留弱特征的 Deep-to-Shallow 门控

上一层解码特征 U_l 上采样至同尺寸。P_l、Q_l 分别将 E_l、U_l 投影至32通道。

```text
A_l = sigmoid(Conv1x1(Act(Norm(Conv1x1([P_l(E_l), G_l, Q_l(U_l)])))))
gamma_l = 0.5 * sigmoid(b_l)
S_l = [1 + gamma_l * (2*A_l - 1)] * E_l + eta_l * R_l(G_l)  # A+B
D_l = existing_DoubleConv(concat(U_l, S_l))
```

A_l 输出与 E_l 相同通道数；b_l 初始为-4，使乘法调制接近恒等。系数始终在0.5至1.5范围内，降低直接关闭弱浅层信号的风险。该设计只表达意图，仍可能压制细分支。

消融定义必须固定：

- 无A无B：直接使用原 E_l，恢复原解码路径。
- 只有A：上述 A-only 残差上下文注入，无门控。
- 只有B：G_l 来自最近一个更深层 E_(l+1)，无多尺度选择、无上下文残差注入。
- A+B：完整公式，多尺度上下文同时用于门控和残差注入。

实现成独立模块和配置开关，关闭开关时不额外改变解码器通道。不要为了实现门控同时更改全部主干归一化、深度、窗口或训练增强。

### 3.4 为什么暂不增加更多模块

暂不叠加 Mamba、额外全局 attention、ASPP、预测法向引导注意力或多任务几何头。先证明这一个 D2S 模块优于普通拼接和普通 Attention Gate。它们都是备选研究，不能一开始全部变成必做工作。

已有 Attention U-Net 使用语义门控，因此“深层引导浅层”不是新概念。本方案的新颖性仍需通过多尺度选择、残差设计、薄曲面任务适配及对照实验判断，不能预先写“首次”。

## 4. 新损失的定稿候选

```text
L_total = L_seg + lambda_t * L_trace + lambda_p * L_profile
L_seg   = 0.6 * L_Dice + 0.4 * L_Focal(alpha=0.75, gamma=2)
```

基础项延续当前配方，先修复 FP32。它不是创新。探索起点 lambda_t=0.05、lambda_p=0.1，均为本方案启动值，不是文献最佳值。

从先验上优先实施 profile，再实施 trace。旧诊断提示近邻误报/薄面定位突出，但应先在修正 B0 的验证预测上重新确认。如果 trace 没有可重复收益，删除该项并如实修改论文表述，不能为了迁就简历强行保留。

### 4.1 L_profile：沿曲面法向控制位置与响应宽度

给定标签上的采样点 q_i 与局部无向法向 n_i，在法向两侧采样：

```text
x_ij = q_i + t_j * n_i,  t_j = [-3,-2,-1,0,1,2,3] voxel
p_ij = trilinear_sample(sigmoid(logits.float()), x_ij)
y_ij = trilinear_sample(label.float(), x_ij)
a_ij = (p_ij + eps) / sum_j(p_ij + eps)
b_ij = (y_ij + eps) / sum_j(y_ij + eps)
m_i  = (a_i + b_i) / 2
L_profile = mean_i [0.5*KL(a_i||m_i) + 0.5*KL(b_i||m_i)]
```

使用自然对数与 FP32，eps起点1e-6。预测与标签必须使用完全相同的 grid_sample 坐标和插值；不能将所有亚体素曲面点强行赋值1，否则会与斜面的栅格标签冲突。

这项直接约束最终概率图：变厚时质量分布扩散，偏移时概率峰错位。它只比较相对分布，不保证绝对概率足够高，因此必须和 L_seg 一起使用。也不单独保证三维方向或连通性正确。

首轮每体抽取最多1024条有效剖面，每条7点；有限几何缓存可以大于1024，训练随机子采样。无有效剖面返回与 logits 相连的零损失，不返回 NaN。

跳过：越界、无有效GT质量、明显多面混合、法向不可靠、人工裁剪边缘。剖面遇到两张真实断层时不可把另一张当负样本压制。置信规则由标签几何决定，不能按模型预测挑容易样本。

### 4.2 L_trace：二维断层迹线的连通性

三维断层是薄曲面；二维非掠切剖面才通常呈现细线。对抽样二维剖面/局部窗口的预测概率和标签计算可微 soft-clDice：

```text
Tprec = (sum(S(p)*y) + eps) / (sum(S(p)) + eps)
Tsens = (sum(S(y)*p) + eps) / (sum(S(y)) + eps)
L_trace = mean_valid [1 - 2*Tprec*Tsens/(Tprec+Tsens+eps)]
```

S 是二维可微软形态学骨架算子。不能对预测先阈值化、转 numpy、做硬骨架后再声称反向传播。

首轮每体最多6个有效64×64窗口，三个切片方向各最多2个；soft skeleton初始迭代10次，需用标签宽度和小样例验证充分性，不能假定固定次数适用于所有标签。整个操作保留 autograd，单独记录耗时。

适用性筛选（实施候选，阈值需验证）：

- 切片法向 s 与局部曲面法向 n 的 |n·s| 过大意味着近乎平行切过曲面，易出现宽面状足迹。首轮要求窗口内可靠几何点的大多数满足 |n·s|<0.85，且足够比例前景点有可靠几何。
- 排除主要由厚面状足迹构成的窗口；不对零散前景像素乘筛选掩膜后骨架化，这会人为制造断点。按整个窗口选取或跳过。
- 无GT前景窗口跳过 trace，但始终保留 L_seg 的背景监督。
- 预测全空且GT非空时应得到高损失、有效梯度。边界外至少保留一圈形态学操作 halo，计分时避开受padding影响的边缘。

这只是局部迹线连续性辅助项。不能引用 clDice 的理论就声称我们保证三维断层网络拓扑、X/Y关系或分离断层数完全正确。真实终止、Y截断和P分离都是合法结构，不设“全体只有一个连通分量”的目标。

### 4.3 同一损失如何用于 Thebe：统一使用标签派生几何

为避免合成集依赖精确曲面而 Thebe 无法计算完整损失，本方案主实验统一从二值训练标签估计局部几何。无需额外人工法向标注；这属于标签派生目标，不是独立真实法向真值。

第一版缓存方法：

1. 在正标签体素中按空间网格分层抽候选点，避免仅抽密集大断层。
2. 对每点半径约4体素的正标签邻域做局部 PCA，最小特征值对应特征向量作为 n。
3. 特征值排序 e0<=e1<=e2；首轮要求至少16个邻域点、e0/(e1+eps)<0.25、e1/(e2+eps)>0.2，以排除明显非平面或近线状邻域。这些数值是待检验启动值。
4. 近邻多面/交汇不能仅靠PCA判定：在合成数据用已保存曲面核查过滤漏检；Thebe增加局部平面残差、剖面多峰及空间连续性检查，仍需抽样可视化。靠近的平行双面可能骗过PCA，不能宣称已可靠解决。
5. 记录有效样本覆盖率、不同方向覆盖率及被跳过原因。若Thebe覆盖率过低，必须报告，不能让几何项长期为零却声称使用了相同有效监督。

q 可以是标签体素点，不要求精确落在连续中间面；预测与标签在同一剖面比较。n与-n对应反向采样，JS不应变化。坐标只按索引空间解释，Thebe时间轴未换算物理距离前不称“真实地质倾角”。

合成数据的 surfaces 用于核查法向误差、多面过滤及机制评价，默认不偷偷提供给主实验训练更强的监督。若后续比较“精确合成几何监督”，另列实验，不和主损失结果混在一起。

增强必须同步变换采样点、法向与所有窗口坐标；旋转/翻转后的标签与几何要可视核对。tensor 为 z/y/x，grid_sample 最后一维为 x/y/z；align_corners=False 时索引 x 归一化为 2*(x+0.5)/W-1。

### 4.4 训练次序与最小参数搜索

- 前5%的训练更新仅使用 L_seg，随后10%更新将几何权重线性增加至目标值；各组统一主优化器配方。
- profile候选权重0.05/0.1；trace候选0.02/0.05。先分别尝试，避免大网格搜索。
- 记录每项原始值、加权值、有效采样数；间隔若干更新检查其对共享层梯度的量级与有限性。
- 不因某组训练不稳定就单独追加预算、换增强或调基线；调整形成新协议时相关组一起重跑。
- 若profile只是压低弱分支Recall，或trace产生错误桥接，应修改/放弃该项，而不是只保留总IoU上升的说法。

## 5. 收拢后的实验设计

### 5.1 主对比

两个数据集分别独立监督训练、各自在预先划分的测试区域评价：

1. 3D U-Net。
2. 3D ResNet50-UNet。
3. 强化 MaxViT3D B0。
4. 改进 MaxViT3D（A+B+完整候选loss）。

投稿版本优先增加一个可复现的3D Transformer基线，例如无私有预训练的 SwinUNETR；它比增加一大批迁移实验更贴近模型论文的核心论证。此项在四模型流程稳定后做。

保持每个数据集内划分、输入尺寸、主损失基线、实际batch、优化器更新预算和模型选择规则一致。新模型使用额外几何损失是被研究的差异，后续的loss-only组负责区分结构收益。

Thebe沿crossline使用[0:900)、[900:1100)、[1100:1803)；训练128³裁块，验证/测试128³滑窗、步长64，融合logits。先空间划分再裁块，禁止重叠块跨分区或按GT占比筛选完整测试区域。具体每轮样本数和优化器更新数先确定后冻结。

合成数据沿用800/100/100 manifest，不重新划分来寻找更好成绩。Thebe和合成数据不拼成一个随机拆分的数据池。两数据集可按其规模选择不同训练预算，但同一数据集内比较必须可比。

### 5.2 合成集主要消融：8组覆盖核心归因

| ID | 多尺度A | 门控B | trace | profile | 目的 |
|---|---|---|---|---|---|

### 5.3 Thebe只做4组核心确认

E0、E3、E7、E6（或最终胜出的简化方法）。分别回答网络是否有效、loss是否有效、组合是否有效。它们与主对比复用。

探索单种子，最终关键组至少3种子；不是要求每个候选参数组合全部3种子。测试集不用于决定删除哪个模块。由于既有合成测试报告已被查看，后续选择都在验证集，记录测试访问历史并限制最终结论强度。

### 5.4 必要的少量机制对照

在合成验证集先筛选，仅将关键结果扩展为正式实验：

- D2S对比通道预算相近的普通拼接融合/普通Attention Gate，避免只证明加参数有用。
- profile对比相同采样点上的BCE，区分“多监督了断层附近”与“剖面分布约束”本身。
- 最终保留profile时，至少选一个标准Boundary Loss对照；注意它通常使用标签区域边界，和断层中间面不是同一目标。

暂不做：全套S→T零样本、S→T微调、少样本比例、多个OOD生成器与私有自监督预训练。这些不是当前主线的必要完成条件。

## 6. 评价与展示：每项创新对应证据

核心指标：IoU、Dice/F1、Precision、Recall、AP/PR-AUC（注明实现和聚合方式）；另报告参数量、峰值显存、128³推理耗时和训练开销。Thebe完整区域计数，重叠体素只算一次。

机制证据：

- 门控：固定Recall下的Precision/FP、背景远距离误报、弱分支Recall；必要时只做固定验证体的轻微噪声扰动诊断，不扩展为一整套域泛化项目。
- profile：相同GT采样点上的概率剖面，峰位置偏差与响应宽度；同时报告绝对概率，避免归一化掩盖低响应。
- trace：独立于训练窗口抽样的固定剖面迹线指标，附真实缺口/错误桥接案例；不把二维指标说成完整3D拓扑保证。
- 三维：合成五类分组，特别关注listric与horsetail，以及X交汇、Y终止、P分离局部失败；至少展示未改善案例。

保留现有三列陈列习惯，另增加“输入、GT、B0、改进、FP/FN”的同位置局部对照页及法向概率曲线。样例ID和视角在验证阶段冻结，不按测试成绩挑图。

Thebe的ODS/OIS如果用于对比文献，必须复用或严格对齐作者边缘匹配流程；不能直接与体素Dice混排。模型升级主结果用统一的体素指标即可，是否另做ODS/OIS取决于最终比较的论文。

多种子统计报告均值与标准差。Thebe来自单测区且窗口重叠，不能把每个patch当独立地质样本虚增统计显著性；若做bootstrap，用空间块并说明相关性限制。
