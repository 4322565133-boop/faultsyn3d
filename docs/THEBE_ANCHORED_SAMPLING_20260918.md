# Thebe下一版训练抽取规则：75%前景锚定与密度分层

状态：设计方案，未修改当前训练器、未启动训练。用户目标是增加含正断层标签的训练窗口。这里“含标签”指含正标签；全背景窗口仍有负类标签，也是监督数据。

本方案作为下一轮**训练配方对照**，优先于SC_MAXVIT_DESIGN_20260918.md里“暂时冻结均匀抽样”的建议：先确认抽样配方，再让UNet、MaxViT和新模型共享它。现有训练日志与旧方案保留，不能把训练配方收益直接归因于新网络。

## 1. 针对当前代码的诊断

当前FG50先随机抽128³，然后检查有效区域中正标签比例是否达到0.5%；前景分支不满足时重抽，另一半不检查正标签。它不保证正例落在中心64³，也不保证每个全局batch的比例。

本轮从训练标签和信号重新核算旧审计中的384个原始窗口（epoch47），结果见 `reports/thebe_sampling_design_20260918/audit384.json`。只读取train区域，使用当前信号mask，比例分母为有效体素：

|类型|窗口数|
|---|---:|
|没有正标签|186 / 384，48.4%|
|有正标签但占比低于0.5%|46 / 384，12.0%|
|正标签占比≥0.5%|152 / 384，39.6%|
|含正标签但中心64³没有正例|80 / 198，40.4%|
|达到FG50门槛但中心64³没有正例|34 / 152，22.4%|

样本来自一个epoch的一部分，不能当整个训练集固定比例。训练loss覆盖有效128³，所以外围正例**并非无效监督**；锚定到中心的动机是增加具有较完整周边上下文、与评价核心位置一致的正例曝光。

## 2. 固定配额

维持128³输入、每轮2400窗口、有效batch8、原loss和增强。下一版每个全局有效batch按以下配额取样，并随机打乱槽位：

|分支|每8窗口|每2400窗口|条件与目的|
|---|---:|---:|---|
|常规前景|4|1200|有效区域正标签比例≥0.5%，中心64³有正标签|
|稀疏前景|2|600|0<正标签比例<0.5%，中心64³有正标签|
|普通随机|2|600|沿用v3-U，只检查有效信号≥25%，不按正标签筛选|

因此至少75%的槽位保证含正标签；随机分支也可能抽到前景。若其空块概率接近本次48.4%，预期全背景块约12.1%、含正标签块约87.9%。这是基于混合比例的估算，正式以生成的epoch清单实测为准。

75%是针对本项目的首个待验证起点，不是理论最优比例。增加含正例窗口不等于要求提高正体素总体占比；给稀疏块留名额可能使平均正体素比例低于只偏好大断层的方案，但让更多种类的正例参与梯度计算。

“稀疏”只描述窗口标签占比，不自动等于弱振幅、微小断层或地质复杂。不能仅凭标签密度给窗口加上这些难例名称。

## 3. 先选正例锚点，再裁窗口

1. 仅用训练分区内有效且允许监督的正标签构建轻量空间索引。每个128³空间单元保留正例候选/计数和可重现的有限坐标样本，不必把所有正体素坐标全部加载到内存。
2. 优先均衡选择有正例的空间单元，再在单元内选正标签坐标p。不要直接在全部正体素中均匀抽样，否则大面积、厚标签断层更容易垄断前景配额。空间单元均衡也不等于断层实例均衡；当前二值标签没有可靠实例ID。
3. 为每轴随机选u∈[32,95]，使裁剪起点o=p-u。这样p位于128³窗口的中心64³内，但不是始终位于固定中心点，减轻位置偏置。
4. 优先在不跨训练分区的合法起点范围内抽样。对于无法把边缘正例放进核心的坐标，可以使用仅本split内读取、越界无效补零的窗口；必须维持有效信号≥25%，不从邻区补振幅。记录这类边界窗口占比，所有模型采用同样规则。
5. 根据实际裁出的标签和有效mask计算密度并归入常规/稀疏候选池。必须再次确认中心有正例、所有监督来自train。不要把“选到了稀疏空间单元”直接当作“最终128³窗口也稀疏”。
6. 候选池按空间单元分组抽取，中心位置每轮继续扰动；限制同一batch重复使用同一区域，记录窗口去重率和空间覆盖。没有可靠实例标签时，不声称能均匀采每一条断层。

候选构建主要读取标签及已有支持索引，确定位置后再加载地震体；相比当前每次失败都读取完整振幅窗口，有机会降低浪费，实际吞吐必须测量。

密度条件是抽样分层规则，不改变原始标签。稀疏池若缺少足够空间多样性，先报告覆盖与重复率；可将不足的稀疏槽位显式回退普通前景并记录实际配额，不能悄悄反复复制极少数窗口或宣称已满足25%稀疏比例。没有足够前景候选则停止构建并给出诊断，不无限重抽。

## 4. 四卡训练要真正实现“6正例＋2随机”

当前DistributedSampler使用全局shuffle，简单写index%8不能保证每个有效batch配额。应预先生成本epoch的300组窗口，每组4常规、2稀疏、2随机，在组内随机打乱，并记录坐标/分支/增强种子。

随后按rank和microstep分配到四卡；若继续使用DistributedSampler，需关闭其二次shuffle并验证分配后的全局有效batch。每卡batch2、累积1与每卡batch1、累积2都必须在聚合8样本后满足配额，不能只检查单卡或单microbatch。

抽样RNG与增强RNG分开，不让拒绝重抽的次数改变旋转/模糊随机流；种子由基础seed、epoch、全局slot确定，不依赖worker数量。所有模型复用同一epoch坐标及增强参数表。

## 5. 保留哪些背景，暂时不做什么

25%随机分支继续提供自然训练窗口分布；前景窗口本身也包含大量负体素。首轮不改成100%前景，不再叠加只追求Recall的loss权重。

首轮不加入模型相关的困难负例挖掘。若后续确认FP升高，可另做仅训练区域的难负例分支，但不能根据验证/测试错误位置回抽训练。也不根据测试集分数决定前景比例。

训练loss仍覆盖有效128³；中心锚定只是改变抽样，不在同一轮再改为只训练64³或新增中心加权。评价完全保留spatial-v3，不用前景筛选验证/测试。

## 6. 上线前的核验及对照

先生成一个2400窗口epoch清单并审核：

- 实际含正例率、核心含正例率、稀疏/常规/随机比例、信号支持率、正体素比例分布。
- 深度/水平空间覆盖、不同空间单元数、同batch重复率、跨epoch重复率、边界补零比例、回退次数。
- 多worker/四rank拼接后坐标一致、6+2配额满足、没有读到train范围外数据。
- 数据加载吞吐与原FG50比较；这一步不需要训练新模型。

随后固定loss/模型/预算，对UNet和MaxViT分别比较v3-U、现有FG50、新的前景锚定分层方案。训练预算不因抽样含更多正例而增加。30轮只作中期诊断，正常情况下完成100轮，比较完整验证IoU@0.5、AP及P/R。

若只需要判断训练配方是否有效，整体对照即可；若论文要解释是哪一环节有效，则补单独的“75%原随机拒绝采样”和“75%锚定、无稀疏配额”对照，避免将比例、锚定、分层收益混写成一个因果结论。

抽样属于强基线训练配方，不作为SC-MaxViT的新网络贡献。确认后给所有模型使用同一配方，再评价架构的独立增益。不能只给新模型换抽样、对照仍用旧0.3954分数。
