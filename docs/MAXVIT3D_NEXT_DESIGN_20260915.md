## 1. 推荐结论

最适合当前项目的主线是：

**保留全分辨率细节的 MaxViT3D + 深浅语义融合 + 沿断层面聚合 + 法向剖面定位监督。**

核心直觉：在断层面上连接弱响应，在垂直断层面的方向上控制位置和厚度，在交叉/分叉处允许多个方向。

执行时分成两级：

- 第一版：稳定基线 + 轻量残差 D2S + 法向剖面损失，先确认定位和弱分支是否改善。
- 论文候选版：加入预测法向引导的沿面聚合及多曲面歧义处理，使几何监督真正参与分割特征计算。

不把所有候选一起加入第一版。普通跨尺度融合、普通边界损失、法向辅助头本身都有大量相关先例。需要验证的是面状几何、交汇处理和分割误差之间的具体联系，不能提前宣称首次或保证 TGRS 录用。

相较先前 RESEARCH_IMPLEMENTATION_PLAN 的调整：**把多视角迹线 clDice 从首选损失降为后续对照；把垂直曲面的定位约束提升到第一优先级。** 依据是当前已保存的误差距离诊断，而非个人对某种 loss 的偏好。

## 2. 当前证据支持什么

### 2.1 模型与已有消融

当前 models/maxvit3d.py 是 timm_3d 的 MaxViT 编码器 + 卷积解码器，不是医学 MaxViT-UNet 全部模块的原样复现。

CPU 实例检查得到：

- torch 2.10.0+cu128，timm_3d 1.0.1。
- 默认模型约 40.090 M 参数；full_res_skip + img_size=128 约 40.164 M。
- 编码器输出步长 2/4/8/16/32，通道 64/64/128/256/512。
- 默认 partition_size=(2,2,2)；img_size=128 时为 (4,4,4)。窗口扩大并未单独带来显著收益。
- 编码器有 34 个 BatchNormAct3d、44 个 LayerNorm。解码器使用 InstanceNorm，不能由此推断整个模型没有 BatchNorm。

同一轮 OneCycle 配方的最佳验证记录：

| 配置 | Val IoU | Precision | Recall |
|---|---:|---:|---:|
| 原 MaxViT3D | 65.33% | 68.50% | 93.39% |
| + full_res_skip | 70.25% | 73.33% | 94.37% |
| + drop_path=0.2 | 64.80% | 67.59% | 94.01% |
| + img_size=128 | 66.11% | 68.27% | 95.42% |
| 三项同时加入 | 71.02% | 73.64% | 95.23% |
| U-Net | 70.19% | 72.39% | 95.85% |

这是验证集、单训练种子的探索结果。full_res_skip 提升约 4.92 个百分点，是最明确的结构线索；它应成为强化基线的一部分，单独报告，不能隐藏在新模块中计为新贡献。

### 2.2 错误形态

logs/analyze_maxvit_fixes.txt 在验证集记录：

- 原 MaxViT 的 86.9% FP 距最近标签体素小于 2 个体素。
- 1 体素容差下 P/R/F1 约为 93.0%/96.8%/94.8%。这是容差体素匹配，不是真实连续曲面的 surface Dice，也不惩罚所有多对一过厚匹配。
- 最低位移代理分箱 [0,0.25) 的漏检率约 43.9%；full_res_skip 后约 38.6%；all3 后约 33.1%；U-Net 约 29.3%。
- 原 MaxViT 的 listric 类 Val IoU 约 47.26%，明显弱于 en_echelon 的 79.16%。

合理推断：薄面定位、过宽响应、低错距区域、低角度弯曲分支值得优先研究。

不能由上述数字直接推出“87% 都是厚度错误”或“断层断裂是全部问题”。位置偏移也会落在近邻 FP 中；必须沿法向查看概率剖面和预测图。confidence 是生成器的位移代理量，不是可观测性真值，不能把该分箱直接命名为图像置信度。

### 2.3 新配方仍在改变结果

审计快照：U-Net oldrecipe 200 轮、最佳记录 Val IoU 80.73%；MaxViT all3 oldrecipe 78 轮、最佳记录 78.55%；ResNet oldrecipe 89 轮、最佳记录 76.77%。后两项当时未完成既定 200 轮预算。

这些是日志最佳 IoU，不一定对应最低验证损失选出的 best.pt；不能与旧 test.json 混排，也不能把两种配方之差归因为 focal 单项。配方同时改变了学习率、训练预算、增强、损失、种子、批量和模型选择规则。

## 3. 在创新实验前修复的工程问题

### 3.1 Dice 的 FP16 求和风险：已用最小样例复现

train/train_old_recipe.py:74 的 probs 由半精度 logits 得到，probs.sum 没有明确指定 float32。128³ 个 0.5 的和为 1,048,576，FP16 返回 inf。即使平均概率仅超过约 3.12%，也可能超过 FP16 最大有限值 65,504。

本次 CPU 半精度最小复现：相同零 logits 与标签，现有 loss 半精度输入约 0.618417，转为 FP32 输入约 0.583118；差异来自中间求和溢出造成的 Dice 失真，最终 loss 仍可为有限值。

下一步在新实验入口中用 logits.float()/target.float() 计算损失，并关闭 loss 段 autocast；记录 Dice、focal 独立项和梯度。需要分别验证损失值、梯度有限性及与 FP32 参考一致。此检查不是 GPU 全流程重跑，不能据此宣称所有历史指标作废，也不能把历史配方称为已经数值验证正确。

### 3.2 测试程序未恢复模型配置

train/evaluate.py:41 只调用 build(name)，没有恢复 checkpoint 中的 mkw。它不适合直接评价 full_res_skip/img_size 改版，可能加载失败或构造不匹配模型。

下一步集中实现一个模型配置解析函数，训练、分析和测试复用；记录数据/划分/训练源代码版本、checkpoint 哈希、阈值和模型 kwargs。旧默认模型的 test.json 不因此自动失效。

### 3.3 梯度累积与批量统计

编码器存在 BatchNorm，micro-batch=2 累积 4 次不能直接称作 batch=8 前向训练的严格等价。空间维度也参与 BN 统计，因此不能反过来断言小 batch 的 BN 一定失效。

固定实际每步批量；有证据再单独比较冻结 BN 统计或使用 GN 的版本。它们是配方/工程因素，不与创新模块同时变化。

### 3.4 正负权重和阈值

当前 GDice+BCE 依据每个 batch 的正样本比例动态计算 pos_weight。整体 3.475% 前景比例对应约 27.8 的负正比，但每体实际不同。强正类权重可能影响精度—召回平衡，应在验证集对普通 BCE、适度加权 BCE、现有 Dice+focal 做小规模受控比较。

先画验证 PR 曲线，同时报告固定 0.5 和验证集选择后冻结的阈值。若厚度问题主要由阈值解决，应承认这是校准收益。不要仅根据当前高 Recall 就继续加大 FN 惩罚。

### 3.5 增强口径

oldrecipe 的全局正比例强度缩放和常数平移位于逐体 z-score 之前，数学上大部分被归一化抵消；不能作为有效幅度增强的证据。交换 z 与水平轴会改变当前沿 z 子波卷积形成的统计，需要作为单独域随机化因素检查，不能自动当作物理等价变换。

## 4. 模型设计

### 4.1 强化基线 B0

优先 full_res_skip=True、img_size=128；drop_path 在统一修正配方下选择后冻结，不能预设 0.2 最优。保持浅层 16 通道、全分辨率解码 32 通道作为起点。

B0 不含新的几何模块。记录原基线与 B0 的区别。最终还要对比充分训练和合理调参的 U-Net，不能只超过原始 MaxViT。

### 4.2 第一版模块 A：轻量残差 Deep-to-Shallow 融合

在 32³ 和 64³ 解码阶段，分别将两个较深层特征投影至 32 通道、对齐并融合为 G_l。先不将全部深层特征展开到 128³，也不添加全体素全局注意力。

    G_l = sum_j softmax(a_l)_j * Up(P_j(E_j))
    A_l = sigmoid(Conv([P_l(E_l), G_l, Up(D_{l+1})]))
    S_l = [1 + gamma_l * (2*A_l - 1)] * P_l(E_l)
    D_l = Block([Up(D_{l+1}), S_l, G_l])

gamma_l 约束在 [0,0.5]，初始化接近 0，保证初始近似原 skip，且浅层信号不会被完全关闭。这里保留弱分支的通路比一开始强门控更适合当前问题。

这是合理的模块基线，不单独声称原创。必需对照：简单拼接、普通 Attention Gate、参数量接近的卷积融合。

### 4.3 论文候选模块 B：预测法向引导的沿面聚合

普通 D2S 只回答“哪里值得关注”；本模块进一步回答“从哪个方向聚合邻域信息”。先只放在 64³ 一层，投影通道 16–32，邻域 3×3×3。

几何头预测局部单位法向 n_hat。用 N=n_hat*n_hat^T 表示无向法向，因此 n 和 -n 的表示相同。邻域位移 delta 沿法向时 delta^T*N*delta 较大，沿切平面时较小。

候选局部权重：

    b(x,delta) = delta^T N(x) delta / (||delta||^2 + eps)
    w(x,delta) = softmax_delta(content_score(x,delta) - kappa(x)*b(x,delta))
    F_new(x) = F(x) + gamma * sum_delta w(x,delta)*V(x+delta)

几何项是软偏置，保留内容相似度和原始残差；初始 kappa 很小，几何预测稳定后再增加。禁止推理时输入 GT 法向或 GT 树。

这能检验“在断层面上借用上下文，减少向法向扩散”的假设。它也可能跨接相近断层，故不能宣称天然保持拓扑。局部角度变化大、分辨率较低或法向预测差时，其收益可能消失。

### 4.4 多曲面歧义必须处理

X/Y 交汇处单法向不唯一；靠得很近的两张面也可能在粗尺度混合。增加一个小型歧义头 j_hat，令 kappa(x)=kappa_0*(1-j_hat(x))，歧义区域退回内容驱动的融合。

GT 歧义掩膜由多个曲面在同一邻域内的距离/方向证据构建。它包括难以用单法向描述的交汇和近邻多面区，因此不能直接称为 X/Y 类型分类。用 BCE/Dice 监督并监控歧义覆盖率，防止全图 j=1 使几何分支被绕过。

normal_valid 排除这些区域；不要用 instances 最后覆盖的编号充当交汇唯一方向。不能直接平均正负法向；尺度变化时按局部可靠曲面选择方向或对 n*n^T 聚合后提取主方向，并屏蔽低特征值间隔的歧义区。

若这一步过复杂，先完成 A 和剖面损失，不要用错误的单法向假设强行完成 B。

## 5. 复合损失：从三个有明确职责的部分开始

### 5.1 基础分割 L_seg

候选起点为当前 oldrecipe 的 0.6 Dice + 0.4 focal(alpha=0.75,gamma=2)，先修复 FP32 归约，再与 Dice+BCE 做受控选择。系数是现有配方，不代表已确认最优，更不是创新。

后续模块实验全部固定同一个 L_seg。各项需要记录数值和作用到共享层的梯度，不能只看名义权重。

### 5.2 主推荐：法向剖面定位 L_profile

用 surfaces 中的真实曲面采样点 q_i 及其局部法向 n_i，在法向两侧采样：

    x_ij = q_i + t_j*n_i
    t_j in [-3,-2,-1,0,1,2,3] voxels   （首轮范围，后续用验证集确定）
    p_ij = trilinear_sample(sigmoid(logits), x_ij)
    y_ij = trilinear_sample(binary_label, x_ij)

**两者使用同一坐标转换和插值算子。** 若对预测三线性采样，却给所有亚体素中心强行指定 1、外围指定 0，会与斜面栅格标签冲突。第一版使用原标签的插值值，保持目标口径一致。

将一条剖面归一化为沿法向的概率质量分布：

    a_ij = (p_ij + eps) / sum_j(p_ij + eps)
    b_ij = (y_ij + eps) / sum_j(y_ij + eps)
    L_profile = mean_i JS(a_i, b_i)
    JS(a,b) = 0.5*KL(a || (a+b)/2) + 0.5*KL(b || (a+b)/2)

意义：预测过宽，质量会落到曲面两侧；预测偏移，质量峰位置与标签不同。它直接作用于分割输出，不依赖额外距离头能否把知识传给分割头。

实施边界：

- 它只约束剖面内的相对分布，不能替代 L_seg；所有概率同时缩小可能保留相对形状，绝对检出由 L_seg 约束。
- GT 剖面无有效前景、越界、有限面边缘或多曲面混合时跳过，不能把另一真实断层当负样本压掉。
- 表面点按面积采样，兼顾各实例但限制小实例过采样；首轮每体约 2048 条、每条 7 点。先检验训练吞吐量。
- 在训练集生成/读取曲面监督；验证和测试曲面仅用于评价，推理输入只有地震体。
- 范围、插值和 eps 都会影响结果，必须通过斜面、平移、过厚、缺口与双面小样例检查。
- 这是待验证的任务适配设计，不是已发表的标准损失或已完成的创新。需对比普通 Boundary Loss 和同预算的法向采样 BCE，判断收益是否仅来自改变采样分布。

### 5.3 法向监督 L_normal

    L_normal = sum_x M(x)*(1 - |dot(n_hat(x), n_gt(x))|) / (sum_x M(x)+eps)

M 为窄带内单曲面有效区。背景、交汇、近邻多面和导数不稳定处不监督单法向。全空掩膜返回零。

仅挂法向头时它是多任务辅助；加入模块 B 后，预测方向参与局部聚合，才形成明确的模型—几何联系。不能把法向头准确当作分割方向一定准确，仍需评价分割输出。

不要用地震振幅梯度作为 GT 断层法向，那里主要反映层理；也不要在概率脊线中心直接归一化概率梯度，它可能接近零。

### 5.4 推荐组合和加入顺序

    第一版：L = L_seg + lambda_p*L_profile
    几何版：L = L_seg + lambda_p*L_profile + lambda_n*L_normal
    多曲面版：再加入 lambda_j*L_ambiguity，以监督模块 B 的歧义退让

探索起点 lambda_p=0.1、lambda_n=0.05、lambda_j=0.05；仅作为启动值。记录梯度后调整，分别消融。主损失先预热，再逐步加入几何项。几何头在训练早期预测不好时，模块 B 的方向偏置从接近零开始。

### 5.5 连通性作为有条件的补充

如果剩余错误确为沿面的缺口，再比较：

1. 三方向的非掠切二维迹线 soft-clDice。它适用于线状剖面监督，不自动给出三维薄面拓扑保证。
2. 曲面网格局部邻接对约束：只在同一有效曲面局部片、无真实边缘的邻接点间约束覆盖变化；不能连接不同实例或越过 Y 截断。单独一致性也有全零退化，需要主分割约束。

不要第一版就加入全局 TV、全局倾角平滑、固定 beta_0=1 或“抑制所有分支”。现有数据合法地包含分离断层、X 交叉和 Y 分支，这些统一先验可能惩罚正确结构。

## 7. 除模型和 loss 外，最值得做的方向

### 7.1 首选额外方向：同一几何、多种地震成像条件的配对训练

已有生成器把几何、位移、反射系数、子波和噪声放在不同计算步骤，适合显式拆开随机数流，构建同一断层网络在不同子波/相位/噪声/带宽下的配对观测。

第一步仅对同一现有训练体做适度扰动，标签不变；第二步才按 metadata 确定性重建干净反射模型并多次成像。冻结1000个几何体，派生观测不宣称增加了独立几何样本数。

    L_pair = divergence(p(T1(seismic)), p(T2(seismic)))

两种观测都保留监督 L_seg，先从温和且几何不变的变换开始。大幅降低频率/信噪比可能使细分支无法辨认，不应无条件要求完全相同的高置信预测；后续可做渐进扰动或教师约束，但需要单独验证。

关键检验：同几何上换波形后是否仍定位同一曲面；在背景褶皱、无断层负样本和域外频带上是否少误报。这比只增加随机噪声并命名“域泛化模块”更有解释力。

所有配对观测按原几何 ID 继承 train/val/test，禁止同几何换噪声后跨划分。当前 clean/reflectivity 未作为正式输出保存，不能假设可直接读取；由冻结源代码和 RNG 重放导出时须验证几何/标签哈希。

### 7.2 次选：复杂交汇和合法终止的局部关系学习

利用 surfaces+tree 从真实局部几何生成“应延续、应终止、两面分离、真实交汇”的样例，监督局部连接关系或评估误连接。

难点：树上的 (strike,dip) P/X/Y 是参考方向关系，不是整个体中每一点的局部类别；二值语义掩膜无法唯一恢复 X 交叉后每条实例的身份。不能把实例 ID 当稳定语义类别，更不能仅靠连通组件声称恢复完整断层图。

建议先建立评价集，再决定是否加入关系头。比简单全局 clDice 更贴合网络拓扑，但实现与标注派生成本较高。

### 7.3 低成本高价值：背景反例与受控 OOD

现有全部样本至少含主断层。训练体内有背景，但还缺少整块无断层、强褶皱或成像条纹的专门反例验证。可先利用训练体的纯背景裁块检查误报，再在独立扩展目录生成完整反例。

真正 OOD 应包含未见树型、未见参数区间、不同成像条件；单纯新 seed 是同分布测试。先逐因素，再复合偏移，并报告几何 QC 接受率，避免 OOD 被生成器拒绝机制悄悄筛回训练分布。

### 7.4 暂不优先

- 继续扩大 MaxViT、叠 Mamba/CBAM/ASPP/大核：当前证据不指向模型容量不足。
- 固定三轴大核直接命名“沿断层方向”：固定轴不等于任意曲面切向，除非有显式方向适配。
- GAN/扩散生成代替当前可控生成器：成本高，还可能失去精确标签。
- 全三维持久同调训练：计算和正确目标定义更复杂，先作小体评价或对照。
- 把局部地震重建直接叫 PINN：当前生成器不是完整波动方程求解；反演几何/位移/背景存在非唯一性。

## 8. 消融与停止条件

### 8.1 先把每个贡献分清

所有行使用同一强化基线、配方、划分与实际 micro-batch：

| 实验 | D2S | 法向剖面 | 法向辅助 | 沿面聚合+歧义处理 |
|---|---|---|---|---|
| B0 | 否 | 否 | 否 | 否 |
| A | 是 | 否 | 否 | 否 |
| P | 否 | 是 | 否 | 否 |
| AP | 是 | 是 | 否 | 否 |
| APN | 是 | 是 | 是 | 否 |
| APNG | 是 | 是 | 是 | 是 |

此外比较普通 Attention Gate、普通 Boundary Loss、法向采样 BCE；模块 B 加入前后保持法向头存在，避免把额外监督与聚合机制混为一项。有几何额外标注的组应明确标注，并用只挂辅助头的组控制额外监督收益。

如果论文重点是交汇机制，再单独比较 B 有/无歧义处理。配对成像作为之后独立轴，不混入前述主消融。

### 8.2 指标与可视化

- 全局与逐体 IoU、Dice/F1、Precision、Recall、PR-AUC，按五类和位移代理分箱报告。
- 在 GT 法向上比较定位偏移、响应宽度、剖面覆盖；避免把真实栅格宽度变化误判为模型厚度错误。
- 预测到 GT 薄面的距离及 GT 面覆盖；若提取表面，统一提取方法，不将标签带双侧边界偷换为断层中面。
- 分支恢复、Y 终止、X 交汇与 P 分离区域的误连接/漏连接；明确它们是局部诊断，不是整个树拓扑完全恢复率。
- 同时报告低距离 FP 和远距离 FP 的绝对数/比例。单看 FP 组成比例会混淆分母变化。
- 参数量、峰值显存、128³ 推理时间、大体滑窗接缝。

保留当前三列展示风格：输入、GT/预测对照、错误图；附同一点法向概率曲线。固定展示样例，额外展示最差样例和交汇失败，不能只挑最好结果。

### 8.3 实验纪律

探索先单种子；最终关键比较至少 3 个训练种子，使用体级配对统计。结构和权重在验证集选择。已看过的100体测试若反复影响设计，应新增独立锁定的确认集，保留原1000体不变。

200/400/800 学习曲线目前使用相同 epoch 数，更新步数不相同，不足以单独证明 MaxViT 的样本效率差或过拟合机制。可分别报告相同 epoch 与相近计算预算实验。

决定是否继续某模块：

- D2S 仅与简单拼接持平且明显更慢：删除或简化。
- profile 只靠牺牲弱分支召回提高 Precision：调整或放弃，不算解决问题。
- 法向头变准但分割不改善：不能把辅助任务指标当主贡献。
- 沿面聚合增加 P 类误连接或破坏 X/Y：先修歧义处理，不能只看总体 IoU。
- 仅同分布收益，受控 OOD 明显下降：限制结论，不宣称跨域泛化。

## 9. 相关工作与创新边界

本次为定向检索，不是完整系统综述；摘要可支持方法方向判断，复现精确公式仍需全文。

1. [MaxViT-UNet](https://arxiv.org/abs/2305.08396)：本地卷积解码器版本要准确命名，不能自动视为原论文完整复现。
2. [Attention U-Net](https://arxiv.org/abs/1804.03999)：语义门控已有先例，因此 D2S 的新意不能只来自深层引导浅层。
3. [clDice](https://arxiv.org/abs/2003.07311)：主要验证于管状/线状网络。其理论条件不能直接等同于当前软损失对薄曲面交汇的保证。
4. [Boundary Loss](https://proceedings.mlr.press/v102/kervadec19a.html)：形状/边界距离监督是已有方法，必须作为剖面定位损失的相关工作和对照。
5. [TGRS：Physics-Informed Neural Networks for 3-D Seismic Fault Segmentation With Topological and Geological Priors](https://ieeexplore.ieee.org/document/11208699/)，DOI 10.1109/TGRS.2025.3623694：出版社索引摘要明确列出曲率、持久同调、TV、倾角平滑、连接和分支相关约束。说明“地质先验复合损失”这个大方向已经存在；摘要描述的单连通/无孔倾向不宜直接作为多分支网络的统一目标。全文页面反机器人限制，本次未逐式复现其损失。
6. [FaultEdgeFormer](https://academic.oup.com/jge/article/23/4/1285/8527610)，2026：已结合可训练 Sobel 和改进 Transformer 进行三维断层检测，因此普通边缘分支不宜独立宣称新颖。
7. [Wu 等，2019 多任务地震图像处理](https://academic.oup.com/gji/article/219/3/2097/5571094)：联合断层、去噪和地震反射法向已有先例；这里的断层曲面法向和层理反射法向须区分。
8. [地质断层模型域偏移基准](https://arxiv.org/abs/2505.08585)：可用于设计域偏移评价，不能由合成同分布结果推出真实泛化。

更有辨识度的候选贡献表述：

“利用可控合成网络提供的曲面几何，在多尺度特征融合中学习沿面信息聚合，并通过法向概率剖面约束薄面的定位；对多曲面交汇区域保留方向歧义，以兼顾弱分支恢复和错误连接控制。”

这段是研究假设。需要与上述已有方法逐项对照、消融及域外验证后，才能转成成果表述。

## 10. 最先落地的五件事

1. 单独修复 loss 的 FP32 归约和测试时配置恢复，冻结正式训练协议。
2. 对修正配方的 B0 做验证误差诊断，确认当前仍以定位/弱分支为主，而不是沿用旧配方的错误结论。
3. 建立少量曲面采样缓存，先验证 profile 的坐标、插值和交汇筛选。
4. 完成 B0/A/P/AP 四组，再决定是否投入预测法向引导的沿面聚合。
5. 优先补同几何配对成像与结构 OOD，之后获取真实资料做外部验证。

当前最有价值的优势是可控几何和可靠派生监督；让它们服务于分割的可测错误，比增加一组通用模块更适合这个项目。
