# 当前从零训练审计与下一条模型改进路线

日期：2026-09-16。本次只读检查运行进程、代码和日志，检索相关方法，形成后续方案；没有停止或修改正在运行的训练，也没有启动新的大训练。

## 1. 当前跑的是什么，能否判定失败

当前运行：`train/train_old_recipe_ddp.py --variant full --tag full_oldrecipe_ddp`，四张2080Ti，200轮预算，从随机初始化训练D2S＋profile＋trace。它不是此前20轮继续训练任务，也不是上一份建议中的“只改网络”消融。

本次检查期间训练从约第128轮推进到第138轮；最后读取第138轮验证IoU=0.8131，仍未结束。

| 轮数 | 当前full Val IoU | 历史基线同轮Val IoU |

| 80 | 0.7898 | 0.7904 |
| 100 | 0.7976 | 0.7984 |

解释：训练本身还在提高，不是绝对不增长；主要问题是几乎没有相对基线的增益。可以降低这版组合的优先级，但不能据此断言MaxViT没有潜力，或把尚未单独消融的每个模块都判为无效。

0.833是历史测试IoU，上表是验证IoU，不可直接比较。历史单卡梯度累积与当前DDP也不是严格同一协议，含BatchNorm的统计路径不同；表中只能作参考轨迹。

处理决定：现有实验按已定预算收尾并保留负结果；后续不再给同一个D2S＋双loss组合追加调参预算。仅约1小时剩余预算，保留完整曲线比在中途把它记成正式失败更清楚。运行中的last.pt仅保存模型/轮数，不能直接承诺中断后无损恢复优化器。

## 2. 必须更正之前的数值判断

此前文档以CPU半精度例子指出probs.sum可能溢出，并据此要求重跑基线；这个论证没有复现真实CUDA autocast上下文，推断过强。

本次在未参与训练的T400上，以真实训练标签构造近乎正确的预测，得到：

| 调用 | 求和dtype | sum | 旧函数loss |
|---|---|---:|---:|
| FP16张量，autocast关闭 | FP16 | inf | 0.600000 |
| FP16张量，CUDA autocast开启 | FP32 | 74547.62 | 0.002889 |
| 显式FP32参考 | FP32 | 有限 | 0.002842 |

当前DDP脚本恰好在CUDA autocast内部调用旧loss。因此不能说已经证明其Dice归约溢出，也不能用这个原因解释当前无收益。显式FP32仍是更稳健的函数边界，不依赖调用者是否开启autocast；但其潜在收益属于数值工程，不是模型创新。

前向归约溢出与GradScaler的反向缩放溢出是两件事。之前epoch14/step98跳过并降低scale的恢复记录仍有效。本次探针未启用GradScaler，其未缩放梯度不能用于评价实际AMP训练梯度。

证据：`CURRENT_DDP_LOSS_DTYPE_CHECK_20260916.json`。有关旧文档已加更正说明，不覆盖历史实验结果。

另外，下个统一入口应在分布式验证前同步BN缓冲，或用rank0的同一权重验证全体。当前脚本各rank用ddp.module验证不同子集，最后训练batch后的BN running stats可能不同，这不严格等同于一份checkpoint的单卡验证。此处是评价口径检查，不能据此预设当前指标无效或改善幅度。

## 3. 重新定义改进问题

之前D2S主要调节浅层特征强弱，而现有MaxViT已经包含大量注意力与多尺度特征。重复做语义重加权可能缺少独立作用，这是候选解释而非已证实根因。

下一条路线改为检验具体问题：

> 对细薄、倾斜、弯曲断层，固定上采样与特征尺度对齐是否限制最终位置精度？让解码器学习从哪里取特征，并保留高分辨率细节，能否改善定位？

现有实现的解码阶段使用固定trilinear上采样。它是否构成实际瓶颈仍需通过验证误差诊断和结构消融确认。不能把以前低分OneCycle模型的“近邻FP多”直接当作当前高分模型的同样结论。

## 4. 首选：浅层引导的三维动态上采样/对齐

先只替换32³→64³的一次上采样，保留其余编码器、卷积解码器、full_res_skip和输出头。第一版不要同时更换loss、扩大主干或改所有尺度。

设D为32³深层解码特征、S为64³浅层编码特征：

```text
C = concat(Proj(S), Trilinear(Proj(D)))
delta = r * tanh(OffsetHead(C))
D_aligned(x) = GridSample(D, base_grid(x) + delta(x))
D_out = existing_decoder(concat(D_aligned, S))
```

delta是每个输出位置的3D采样位移，不是断层物理位移。初始r可设为0.5个粗网格体素，允许约1个目标网格体素的位置调整；它是待验证启动值。

实现细节：

- 先通道压缩至16再预测offset；offset可先按整个特征共享，避免每通道都预测三维场。
- 重采样的内容仍可保留D的原通道数，保持existing_decoder输入一致，便于与固定插值作受控比较。
- 使用明确的粗网格坐标单位；align_corners=False时对应坐标为(i+0.5)/scale-0.5。grid_sample最后一维是x/y/z，数组为z/y/x。
- 零offset应在数值容差内复现原trilinear，padding_mode='border'与边界行为需测试。
- offset head可用很小随机初始化；不在整个对齐输出外乘一个接近零的总残差系数，避免整条新路径被弱化。但零初始化本身并非必然无法学习，关键是检查实际梯度与位移。
- 监控offset分布、饱和率、越界比例、边界预测和P类近邻断层错误合并。限制位移不等于保证拓扑。
- 所有引导由输入特征预测，推理不读取GT曲面或标签。
- 如32³→64³有效，再单独增加64³→128³；后者更昂贵，先做显存/速度测量。

这一路线直接改变空间采样位置，和D2S的特征幅度门控不同。仍然不能保证有效，也不能把“2D方法改成3D”本身当成充分的新颖性。

## 5. 第二候选：轻量高分辨率残差细化

如果对齐确有作用，再考察128³细节细化：复用现有全分辨率浅层分支，联合粗分割logit及上采样语义特征，用16通道的1×1×1投影、3D depthwise卷积与1×1×1输出得到局部logit修正。

```text
z_final = z_base + Refine(shallow_full, projected_semantics, sigmoid(z_base))
```

首先只用同一个主分割loss训练；细化头初始化及是否detach粗概率必须固定记录。它可能仅增加冗余参数，故需与等预算普通卷积头比较，而不是只和参数更少的原模型比较。

高分辨率表达用于断层分割已有Fault-Net等先例；应引用和比较。不要将全分辨率分支的已有工程修正重新命名成新贡献。

## 6. loss先简化，避免再次同时改变多个因素

下一轮网络比较统一用显式FP32 Dice＋Focal，不再加入profile/trace。它们留作已尝试候选，不能因为简历写了复合loss就强制保留。

如果独立验证显示主要错误仍在标签附近1—2体素，再尝试普通、可解释的局部带状监督作为对照：

- 正例为GT断层标签；近邻负例为距GT标签不超过2体素的背景。
- 分别取正例和近邻负例BCE的均值，再等权组合，避免大面积背景支配。
- 可试L_seg + 0.05 L_band；权重仅作起点。
- 与标准Boundary Loss和相同采样预算BCE比较，不能把常见重加权命名为全新拓扑loss。
- 在Thebe使用时要考虑标注不完整，不能默认所有未标注邻域都是真实背景。

该项的目的只是检验位置/厚度误差，不保证连通性。若错误主要是弱响应整段漏检，应改变诊断和训练采样，而不是盲目增加近邻负例惩罚。

## 7. 最省实验的执行顺序

1. 当前200轮实验结束后，从验证集固定样本核查薄面位置误差、缺口和背景误报；不再按测试结果调设计。
2. 新协议仅比较B0与“单处动态对齐”。两组从随机初始化、同数据、同更新预算、同选模规则；保存优化器/scaler和实际AMP跳步数。
3. 若有可重复验证收益，再增加高分辨率细化；结构有效后才单独尝试L_band。
4. 投稿前对比普通3D动态上采样、浅层引导版和等预算普通卷积，区分空间对齐、浅层引导、参数量的贡献；核心结果多种子确认。

初筛可以设统一短预算，但200轮cosine的前80轮与80轮完整cosine不是同一训练协议。短预算无收益不能自动证明长预算无效；最终候选与基线必须同预算。

不承诺“这次一定涨几个点”。如果定位诊断不支持对齐假设，先调整问题定义，再决定是否实现这一候选。

## 8. 直接相关的一手资料与创新边界

- CARAFE，ICCV 2019：内容自适应特征上采样已有先例。https://openaccess.thecvf.com/content_ICCV_2019/html/Wang_CARAFE_Content-Aware_ReAssembly_of_FEatures_ICCV_2019_paper.html
- FADE，ECCV 2022：联合编码器、解码器信息产生上采样核，包含细节引导机制。https://www.ecva.net/papers/eccv_2022/papers_ECCV/papers/136870228.pdf
- DySample，ICCV 2023：学习采样位置的轻量上采样，是下一候选最直接的机制参考；原论文收益不能直接搬到三维地震。https://openaccess.thecvf.com/content/ICCV2023/html/Liu_Learning_to_Upsample_by_Learning_to_Sample_ICCV_2023_paper.html
- Fault-Net / MD Loss：三维断层高分辨率特征传播已有研究。https://arxiv.org/abs/2110.05319

因此，真正需要验证的是三维薄曲面下的尺度对齐需求、适配设计及误差改善，不能以模块重命名替代证据。
