# 新实验审计与下一阶段研究方向

日期：2026-09-16。依据当前项目日志、模型代码、thesis/DoubleBlock-ViT.pdf 和作者公开代码制定。

本次完成阅读、参数统计和方案设计，没有修改训练代码、停止训练或启动新的训练。以下新结构尚未完成 forward、显存测试或训练，不能宣称有分数提升。

## 一、研究目标

以 dataset_reproduction_v2 为主要开发数据，研究在与强 U-Net 相近的参数预算下，结合高分辨率细节和 MaxViT 局部/跨窗口建模的三维断层分割模型。

具体目标：约 8–12 M 参数，重点配置接近 U-Net-L 的 9.64 M；在完整训练、公平选模型和多随机种子条件下，争取同时超过 U-Net-L 和现有 MaxViT。参数量、显存、计算量和速度分别报告。四卡 DDP 不会把四张卡显存合并为单模型可用显存。

这是研究目标，不是可以预先保证的实验结果。若保留注意力的模型持续不如公平 CNN 对照，应承认当前数据上的证据边界。

### 2.3 对用户观察的准确解释

认可：v2 是更可靠的研究主数据；强 U-Net 已成为必须超过的对照；直接照搬 DoubleBlock 暂无收益证据。

暂不能证明：

1. “新数据质量太高，所以 U-Net 一定无法被超越”。质量、难度和任务是否依赖全局信息是不同变量。U-Net-L 的复杂类别仍有明显误差，也尚未完整收敛。
2. “旧标签错误有益”。地震观测噪声可能是合理的增强；地震与标签不一致会污染监督和评价，不能当作值得保留的优势。不要人为加错标签来使 Transformer 显得更好。
3. “DoubleBlock 所有组件都不行”。现有实验多为组合和中途结果，仍应精确记录为本实现/本预算下未见优势。

## 三、DoubleBlock 论文真正值得借鉴的内容

### 3.1 阅读方式与来源

本地 16 页 PDF 已提取文字并渲染页面查看，重点看第 6 页 Fig.5/6、第 7 页 Fig.7、第 9 页主结果、第 10 页 Table 4/5、第 12 页 Table 6。未调用不存在的专用 PDF Viewer 插件；使用本地 PDF 页面渲染和图片查看。

公开代码仓库：https://github.com/Laptq201/DoubleBlock-ViT-Unet-segment

核对版本：5b617d72608986f38e602f4dd69b95d45443f5c7；同时检查 models/DB_MaxViT.py 和作者推荐 notebook_DBMaxViT.ipynb。

### 3.2 方法

- 编码：PE-MBConv + 两组局部窗口注意力/FFN。PE 是 Project-and-Excite，沿三轴保留方向坐标的投影统计，经点卷积生成空间门控；不应和普通 positional encoding 混称。
- 相比 MaxViT：SE 换 PE；block+grid 换成 block+block。
- DPF：编码和上采样解码特征共同生成两路权重，进行残差增强、交叉 sigmoid 调制、PE，再与原始 skip 拼接。它比本项目此前只调制浅层的 D2S 更深地参与解码主路径，但同样不意味着必然更适合断层。
- 小模型重新分配通道、层数和瓶颈；不是在大 MaxViT 后面单纯堆模块。
- loss 是常规 Dice 与分类损失的组合，没有独立的拓扑 loss 创新。

### 3.3 论文与代码的差异

- 正文说 shifted windows，但核对的两个实现中两次窗口划分相同，没有 roll/shift/mask，也没有 grid attention。局部窗口之外仍可经卷积、下采样和 PE 获得信息，因此不能说整个网络完全没有跨窗口联系；但不再等同 MaxViT 的 grid self-attention。
- 重复 encoder block 是同一个模块多次调用、共享权重，不是独立堆叠多个参数块。
- 最后 Up2 收到 full-resolution stem feature，却没有使用这个输入。本项目 full_res_skip=True 才补上这条融合。
- 正文 DPF 式(4)描述双路对称门控；代码先更新 x1 再用更新后的 x1 更新 x2，是顺序操作。
- 正文写 0.7 Dice+0.3 CE；公开 loss/推荐 notebook 使用 0.75 Dice+0.25 BCE，Dice 分母也与本项目当前形式不同。
- Table 6 的 2021 最优分配写 1-1-2，邻近正文又写 1-2-2；应明确采用的是代码的 1-1-2。
- Table 5 在 BraTS2021 上给出平均 Dice：U-Net 88.73、加 DB-ViT 88.93、加 DPF 89.29、二者 90.64。这里的消融起点是 U-Net，不能解释为“比已经很强的 MaxViT 必然提高 1.91 点”。主结果中 TTA 也必须单列。

本项目 models/dbvit3d.py 已明确跟随代码实现。直接修改 MRI 通道数、换成断层数据属于迁移/复现；若作为自己模型的关键贡献，需要超出这种替换，并对原方法有明确引用和对照。

## 四、下一条主线：保留空间分辨率的紧凑 MaxViT

### 4.1 可检验的解释

U-Net-L 的三次池化：128³→64³→32³→16³。

现有 MaxViT 的五级降采样：128³→64³→32³→16³→8³→4³。其 full_res_skip 虽然保留了一条浅层路径，但语义主干仍到 4³。

当前 MaxViT 总参数 40.16 M：编码器 30.44 M，dec4 单层约 7.08 M；全分辨率 enc_full 只有 7408 参数。参数分配与 U-Net-L 显著不同。假设：当前细薄表面分割更需要持续的高分辨率局部表达，现有模型给低分辨率语义分配了过多容量。

这是假设，不能单凭上述统计宣称已经找到原因。要用减少下采样、匹配参数的 CNN 对照来验证。

### 4.2 首个模型 M0：先建立能竞争的结构起点

| 层级 | 分辨率 | 初始通道 | 模块 |
|---|---|---:|---|
| stem | 128³ | 36 | 3D 局部卷积，保留完整 skip |
| shallow | 64³ | 72 | stride-2 卷积＋局部卷积 |
| middle | 32³ | 144 | stride-2＋1 个真正的 MaxViT block |
| deep | 16³ | 288 | stride-2＋2 个独立参数的 MaxViT block |
| decoder | 32³→64³→128³ | 144→72→36 | 简单上采样＋concat＋卷积 |

真正的 MaxViT block 保留 MBConv→block attention→grid attention；窗口/网格 partition 初始 4³，head dim=16，MBConv expansion=2，FFN expansion=3。

已用项目安装的 timm_3d 组件在 CPU 实例化参数骨架，计数 **9,489,043**，与 U-Net-L 9,643,495 相差约 1.6%。这不是已经完成的新模型：计数骨架没有完整 forward，也未测试空间 partition 正确性、初始化、AMP、显存或学习效果。额外 norm 和新模块会改变最终计数。

两个可选宽度计数：32/64/128/256 为 7,507,345；40/80/160/320 为 11,702,581。优先用中间预算，避免同时展开多宽度搜索。

保留完整高分辨率路径、减少降采样是已存在的设计方向，不能单独声称全新。Fault-Net 等工作也强调断层高分辨率特征传播。M0 是结构起点和假设检验，不是已完成的论文创新。

### 4.3 唯一优先新模块 M1：面状局部聚合，保留 grid 全局联系

在 M0 的 MBConv 局部卷积部分，测试面向断层表面的方向分支：

1. 保留普通 3×3×3 depthwise 卷积，提供任意方向基本局部表达。
2. 增加 1×k×k、k×1×k、k×k×1 的 depthwise 分支，初始 k=5，捕获三种坐标平面内的上下文。
3. 用仅来自当前特征的小型 1×1×1 预测器生成空间权重，融合三方向分支。增加的特征通过正常残差路径参与输出，不把整个新分支长期压在极小系数后面。
4. 后接原本的 block/grid attention，保留跨窗口的信息交换。

为什么适合尝试：断层是薄面；局部面状连续性与跨区域关联可能互补。为什么可能失败：三个坐标平面不等于任意倾角断层切平面；局部反射层也具有面状结构，可能增加误报；交汇处也不能强迫为单一方向。

因此不要称它已经“识别地质走向”。比较普通 depthwise、大核各向同性 depthwise、三平面固定融合、三平面自适应融合；记录近断层误报、交汇处召回和各类别结果。参数增加应很小，必要时微调通道保持 8–12 M。

平面/方向卷积本身也有既有研究；论文贡献是否足够还需针对这一最终实现做文献检索，不能因换名称就宣称原创。

### 4.4 与前一份动态上采样建议的关系

动态上采样没有被 11 epoch 的日志否定。但新结果提示更优先验证整个编码器的分辨率/容量分配，先建立同预算基线；动态上采样降为第二阶段可选项。不要同时加入面状模块、动态采样、DPF 和多种 loss，否则再次失去因果解释。

## 五、Loss 的研究顺序

### 第一阶段

统一显式 FP32 的 0.6 Dice + 0.4 Focal；U-Net-L、紧凑 MaxViT、改进模块全部相同。暂不加 profile/trace，先证明结构有收益。

如要比较 Dice+BCE，也给 CNN 和 Transformer 相同调参预算。论文 MRI 的 0.75/0.25 或 0.7/0.3 不能直接当作断层最佳系数。

### 第二阶段（条件满足再做）

先在验证集确认主要错误是位置偏差还是召回不足。若定位偏差突出，可测试近断层区域平衡分类损失；或者加一个预测无符号距离的辅助 head，但一次只测一种。

距离辅助候选：训练标签生成 d(x)=min(distance_to_foreground(x),r)/r；r 可预先取 4 体素。用前景及其邻近带的 SmoothL1 监督，避免大面积远背景主导。辅助头的初始小权重如 0.05 只是待验证起点。推理只输入地震，训练几何不作为推理输入。

这是已有几何辅助学习思路，不是新的拓扑理论。应增加 U-Net-L+同一 loss 对照，判断收益来自结构还是监督。对交汇/不完整真实标签另作有效性检查；不直接沿用管状目标 skeleton 连通性作为面状断层的唯一质量标准。

## 六、最小实验矩阵与决策

| ID | 结构 | loss | 问题 |
|---|---|---|---|
| B0 | U-Net-L 9.64 M | 固定分割 loss | 强 CNN 的完整成绩 |
| B1 | 现有 MaxViT 40.16 M | 同一 loss | 历史骨干在统一协议下的成绩 |
| M0 | 紧凑三次下采样 MaxViT 约9.49 M | 同一 loss | 分辨率/容量分配是否改善 |
| C0 | M0 同拓扑、注意力换成匹配预算 CNN | 同一 loss | 注意力是否真的有用 |
| M1 | M0＋面状局部聚合 | 同一 loss | 核心模块有无增益 |
| M2 | 有效结构＋一种几何辅助 loss | 分割＋辅助 | 最后检验监督贡献 |

分阶段执行，先 B0/M0；M0 完整训练接近强 CNN 后，再 M1 和 C0。B1 统一复跑和最终多 seed 不能用历史单次结果完全替代，但可在机制筛选后集中做。

执行要求：

1. 冻结 v2 数据和划分，网络只读地震；不要为使模型胜出降低数据质量。
2. 新旧脚本参数、loss dtype、BN/IN/GN、优化器、增强、全局 batch、学习率日程、checkpoint 选择规则都记录。最新 DDP 已有验证前广播 buffers，不能继续把旧版本问题描述为当前未修复。
3. baseline 和新模型从随机初始化开始；完整实验统一 200 epoch 或预先约定相同早停规则。U-Net-L 的 56 轮 checkpoint 不是最终上限，也不能作为唯一终点对照。
4. 现有 last.pt 不能默认无损恢复训练；后续入口保存 model/optimizer/scaler/scheduler/RNG/sampler/epoch，以支持完整续训。
5. 对 CNN 和新 MaxViT 给相同的小规模 LR 搜索预算，例如 1e-4 与 3e-4。短日程试验和 200 轮日程前 N 轮不等价。11/14 轮主要用于运行检查，不能作方法否定证据。
6. 选结构只看 validation。最终候选 3 个 seed，报告均值/标准差、逐体配对差异和按体积 bootstrap 区间；不把体素当独立样本扩大显著性。
7. 争取验证 IoU 平均提升至少约 0.005 作为工程筛选目标，最终是否成立取决于随机波动和配对区间；不是承诺跑到某个分数。
8. 已多次查看的原 test 不能当作未来无偏调参集。冻结结构后，可用相同生成器、完全独立 seed/几何实例做一次最终 lockbox 检查，所有最终模型一起评估。保留既有 1000 体开发基准，这不要求另做庞大的跨域实验。

## 七、最低限度的误差证据与论文表述

在同一组验证体上固定查看三列：GT、U-Net-L、M0/M1。区分距 GT 1–2 体素的 FP、远离 GT 的 FP、分支 FN、交汇错误、曲面位置误差。记录原生 IoU/F1，同时辅以固定容差的表面/距离指标，不扩大标签厚度来涨分。

主要论点应由实验决定，例如：在相近参数预算下，保留细节的多轴 Transformer 通过面状局部表达和跨窗口关联改善断层分割。不能只写“Transformer 比 CNN 更先进”；如果最终注意力消融没有收益，不能把收益归因于 MaxViT。

此阶段可集中于 v2。未来如果论文声称能用于真实地震资料，仍需至少一个独立真实数据证据；纯合成同分布成绩只支持合成域结论。这不要求此刻展开大量泛化实验。
