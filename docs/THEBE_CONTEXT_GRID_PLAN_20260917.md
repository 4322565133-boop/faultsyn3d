# Thebe 实验与 Context-Grid MaxViT 原型

日期：2026-09-17。目标：以最少的可解释实验验证真实地震断层分割方法，不保证任何模型必胜或 TGRS 录用。

## 一、已做的工作

- 检查本地 Thebe 原始文件头、配对形状、已裁切块的坐标和划分。
- 读取已有 Thebe 两轮训练和全体推理结果。
- 实现 `models/context_grid_maxvit3d.py`，注册模型 `context_grid_maxvit3d`，新增训练入口 variant：context_conv/context_block/context_grid/context_both。
- 原型参数 32,449,615，其中编码器 30,436,344；原强 MaxViT 40,164,233。参数减少约 19.2%，不代表 FLOPs、显存或实际耗时同比下降。
- 检查分区/逆分区、grid 的离散采样、注意力与显式 softmax 参考结果、所有融合模式的输入与参数梯度，以及完整 128³ CPU 前向。完整反向检查状态见 model_checks.json。
- 修复 `train/infer_thebe.py` 的容差 Recall，同时防止无效区域的预测通过膨胀影响有效区域匹配；解析测试通过。

## 二、数据事实与需要避免的坑

### 本地数据

原始 seismic 为 float64，fault 文件与之同形状；代码在使用时转 float32。拼接后的形状按文件轴为 1803×3174×1537，网络轴为 [sample, lateral-3174, section-1803]，即 1537×3174×1803。横向 inline/crossline 文献命名存在容易混淆之处，实验应以文件轴索引和坐标映射为准，不凭名称交换。

保留原 900/200/703 个横向剖面的空间划分：

| 划分 | 原始剖面索引（半开区间） | 已存128³块 |
|---|---|---:|
| train | [0,900) | 2400 |
| val | [900,1100) | 600 |
| test | [1100,1803) | 718 |

裁块全部落在各自空间范围内，未发现跨分区裁块。600个val块相互重叠，不能当600个独立地质体；同工区空间外推也不能称跨工区泛化。

现有test718块只覆盖到全局剖面索引1740（半开上界），遗漏末尾63张及其他轴边界。它们可作快速诊断，不能替代完整test区域的滑窗拼接结果。

### 已有代码的协议问题

1. `synth/thebe_cubes.py` 和 `train/infer_thebe.py` 通过每个split的正标签计算 `depth_band`，因此test评估区域由test真值推导。若作为预先发布的标注ROI本可合理，但这里是本地临时规则，不能将其结果冒称无条件全工区表现。
2. val的45/15/40密度分层说明为“like the test grid”，参考了测试集分布。应冻结一个不依赖test标签的验证协议。
3. `fault_none` 实际是正体素<0.5%，不是严格无断层。背景块误检必须在标签确实全零或明确背景区域统计。
4. 旧全体推理的tol2_recall公式错误；本次已修复，但历史JSON没有改写，需要在统一协议下重评。
5. 原始数据为处理后的专家标注数据，不是所有微小地质断裂均完整标注的物理真值。严格指标衡量与发布标注的一致性；不能通过删掉模型FP自行推定“原标签错误”。

### 新协议（正式实验前完成）

- train内可按训练标签抽样，val/test按预定义空间网格评估，不能根据各自正标签筛掉难区域。
- 主结果覆盖发布的完整非填充区域；填充mask优先使用原始采集/处理掩码。无独立掩码时，采用只依赖seismic的、预先说明的几何支持规则，核查真实零振幅与填充的差别。
- 如果算力限制需要深度ROI，先固定训练信息定义的ROI，并报告为“受限ROI协议”；例如当前训练band=[488,1512)。必须单列完整区域结果，不把ROI分数写成全体分数。
- train随机裁块每epoch2400个，128³，4卡global batch8；第一轮 keep_empty=1，使零/稀疏标签块不被标签密度规则丢弃。更改此规则后所有基线使用同样设置。
- 建立独立版本目录与manifest/hash，不覆盖当前thebe_cubes及正在跑的协议。记录随机patch origin，所有模型相同seed/epoch对应同一裁块。
- val快速网格固定、分数选模一致；每10epoch和结束时执行完整验证区域滑窗拼接，保存全体val-IoU最佳权重用于主报告。若未保存相应epoch权重不能事后把曲线最高值当checkpoint成绩。
- test仅在方案冻结后统一评估；已有test已看过，应承认开发期接触，不能称盲测。
- 推理128³/stride64，高斯融合，末端窗口对齐边界，逐体素拼接后计数一次，不重复计重叠体素。
- 主指标IoU@0.5、Dice、AP、P/R；另报告正确的距离容差P/R和背景预测量。调阈值仅在val确定后冻结；若展示test最优ODS/OIS，只作为oracle汇总，不当部署阈值结果。

## 三、科研问题和新模型

### 假设

已有旧协议MaxViT完整test：IoU约0.3798、P约0.4568、R约0.6925（epoch53）。这提示与标注不一致的预测较多，仍需在修正协议下确认。仅“让预测更连续”可能同时把层理/噪声连成假断层。

候选问题：能否用跨尺度上下文帮助浅层细节判断哪些不连续值得保留，从而改善精确率与召回的平衡？真实数据可能需要更大上下文，但并不预设grid一定优于block。

### Context-Grid MaxViT（工作名称，尚无有效性证据）

保留现有MaxViT-tiny编码器：[64³/64, 32³/64, 16³/128, 8³/256, 4³/512]。

替换主要解码器：

1. 4³深层和8³特征投影融合，得到8³、128通道的上下文。
2. 16³阶段：浅层特征提供Query，深层上下文插值并投影为Key/Value，执行4³-token局部block和空间分散grid交叉注意力；输出96通道。
3. 32³阶段：同样的跨尺度交叉注意力，输出64通道。
4. 64³局部细节融合与128³原始输入细节分支，输出分割logits。

区别：不是保留原解码器再挂一个零初始化残差支路，而是重做主融合路径。仍可能学会忽略上下文，所以必须做控制实验，不能以“在主路径”替代有效性证据。

block/grid/both共享同一组Q/KV投影和相对位置偏置，参数一致；both平均两种注意力输出，计算量不同。其“全局”仅指当前特征块覆盖的输入窗口，不是整个Thebe工区。

不同时删除深层阶段、不同时加入预测法向与多个loss，以免无法解释哪个变化起作用。Thebe没有可直接等同于合成曲面的真值法向，暂不拿二值标注PCA当真实几何监督。

### 第一轮loss

所有模型共同使用已有0.6 Dice + 0.4 Focal，FP32计算，保持结构归因。训练样本分布纠正和评估ROI统一先于loss创新。

若统一协议下仍表现为FP过多，再以共同的BCE+Dice作为简单强训练对照，检查是否只是原Focal的前景权重/采样导致。新loss不是论文必须项；不同时叠加拓扑、方向、边界等损失。

## 四、最少而有效的实验

### E0 数据与实现验收

完成上述ROI、空间网格、mask、无标签依赖的val/test协议；CPU检查之后补空闲GPU上的AMP前后向、峰值显存、DDP和断点续训。新旧结果分开存储。候选不进入当前自动队列。

### E1 真实数据主实验

主线是 **Thebe train监督训练→Thebe独立空间test**，不是零样本泛化。

先做一个seed：

- 强UNet-L（base42）；已有compute-matched UNet b30作为补充，不用小UNet代替全部CNN对照。
- 原强MaxViT，40.16M。
- Context-Grid MaxViT both，32.45M。

从头初始化；相同采样、增强、loss、global batch8。计划100epoch，每epoch2400patch，即30000 optimizer updates，AdamW lr1e-4、wd.01、warmup10、cosine。30epoch只做诊断，不拿提前停止的曲线宣判最终模型胜负。需要调参时给每个模型相同源验证预算。

已有固定采样73epoch、动态采样5epoch结果不能混成同一对比表。GPU资源当前有在跑任务，不自动杀掉或同时挤入新训练。

### E2 核心消融（同一数据与主训练协议）

| 版本 | 目的 |
|---|---|
| context_conv | 解码器容量/轻量化变化本身能否解释收益 |
| context_block | 仅局部跨尺度注意力 |
| context_grid | 仅分散网格跨尺度注意力 |
| context_both | 局部与网格是否互补 |

关键对照是both对block，以及新decoder对原MaxViT。block/grid/both参数相同，FLOPs分别报告；conv对照参数不同，不能称严格等参数。进一步有必要时加等预算的普通self-attention对照，区分cross-scale与一般attention收益。

### E3 确认性实验

仅对通过E1/E2的候选及两条强基线做3个seed；报告均值、标准差、实测时间、Params/FLOPs/显存。统计按独立空间块处理，不把重叠patch当独立样本。

保留v2作为第二数据来源：使用同样架构从头训练，比较域内效果；v2→Thebe零样本只作一次冻结后的补充，不能替代真实主实验，也不与Thebe监督成绩混在一起。若采用v2预训练再Thebe微调，所有基线给相同预训练机会，作为单独训练协议，不是额外结构贡献。

最终补一个合适的领域强基线（如Fault-Net）及必要的现代Transformer对照，按统一协议实现；不要直接拼接文献不同维度/标注/阈值协议的分数。若只在一个真实工区实验，结论限于该工区空间泛化，不声称跨工区普适。

## 五、继续/停止准则

- 一个seed提高不能保证稳定；如果与UNet或MaxViT基本持平且更慢，不继续包装该结构。
- 项目工程目标可设为在统一Thebe评估下绝对IoU改善约0.02并兼顾P/R，但这是筛选目标，不是预测或TGRS门槛。
- 若conv版本即可达到同样收益，贡献应归于解码器设计/容量分配，不能声称grid必要。
- 若grid不优于block，放弃“真实数据天然适合grid”的解释。
- 若仅改采样或常规loss已解决主要问题，应承认结构收益不足。
- 真正可支持论文的结论是：明确的跨尺度机制、独立消融收益、充分训练的强对照、真实数据证据和可接受成本。仅“用了MaxViT+真实数据”不构成充分创新。
